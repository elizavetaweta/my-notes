# 🚪 Порт (сетевой)

> [!abstract] Суть одной фразой
> Порт — это числовой идентификатор (от 0 до 65535), который указывает, какому приложению или службе предназначены сетевые данные. Без портов один IP-адрес мог бы обслуживать только одну программу. Для специалиста по ИБ открытые порты — это потенциальные двери для злоумышленника.

---

## 📌 Как это работает

Если IP-адрес — это адрес многоквартирного дома, то порт — номер квартиры. Письмо приходит на адрес дома (IP), а номер квартиры (порт) указывает, кто именно должен его получить.

---

## 🔑 Известные порты

| Порт | Служба | Протокол |
|---|---|---|
| 22 | SSH | TCP |
| 80 | HTTP | TCP |
| 443 | HTTPS | TCP |
| 53 | DNS | UDP/TCP |
| 3306 | MySQL | TCP |

---

## 🕵️ Значимость для ИБ

- Каждый открытый порт — это потенциальный вектор атаки. Я всегда проверяю лишние порты через `ss -tuln`.
- Злоумышленник может спрятать вредоносный сервис на нестандартном порту (например, SSH на порту 2222).
- При пентесте сканирование портов — первый шаг для разведки.

## 🔗 Связи

- [[ss]] — аудит открытых портов.
- [[iptables]] — фильтрация трафика по портам.
- [[tcpdump]] — анализ трафика на конкретном порту.
- [[nmap]] — сканирование портов.
