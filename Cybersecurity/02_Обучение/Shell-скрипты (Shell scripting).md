# 📜 Shell-скрипты (Shell scripting)

> [!abstract] Суть одной фразой
> Shell-скрипт — это текстовый файл, содержащий последовательность команд [[Bash]] (или другой оболочки), которые выполняются одна за другой. Для специалиста по ИБ скрипты — это способ автоматизировать рутину: резервное копирование, проверку целостности, разбор логов, блокировку IP и оповещения об инцидентах.

---

## 📌 Зачем нужны скрипты, если можно вводить команды вручную

- **Автоматизация.** Повторяющиеся действия (проверить права, найти файлы, перезапустить службу) можно выполнить одной командой.
- **Безошибочность.** Скрипт выполняется одинаково, без опечаток, что критично при массовых операциях (chmod, удаление).
- **Планирование.** Скрипты запускаются по расписанию через [[cron]] без участия человека.

---

## 🧱 Структура простейшего скрипта

1. **Шебанг (shebang)** — первая строка, указывает, какая оболочка будет исполнять скрипт: `#!/bin/bash`
2. **Команды** — любые команды, которые ты вводишь в терминале.
3. **Права на выполнение** — скрипт должен быть исполняемым: `chmod +x script.sh`

**Пример:** скрипт, который выводит приветствие и текущую дату:
  
>#!/bin/bash
>echo "Привет, (whoami)!"echo"Сегодня(whoami)!"echo"Сегодня(date)"
Запустить: `./script.sh`


---

## 🔑 Полезные конструкции для ИБ

- **Переменные:** `log_dir="/var/log"` — сохранить путь, чтобы использовать дальше.
- **Условия (if):** `if [ -f /etc/shadow ]; then echo "Файл паролей существует"; fi`
- **Циклы (for):** `for user in $(cut -f1 -d: /etc/passwd); do echo "Пользователь: $user"; done`
- **Пайпы и перенаправление:** те же, что и в Bash: `|`, `>`, `>>`.

---

## 🕵️ Типовые сценарии для ИБ

**Проверка прав на критичные файлы:**
>#!/bin/bash  
for file in /etc/shadow /etc/ssh/sshd_config /etc/sudoers; do  
ls -la "$file"  
done


**Экспресс-аудит открытых портов:**
>#!/bin/bash  
echo "=== Открытые порты ==="  
ss -tuln  
echo "=== Подозрительные соединения ==="  
ss -tanp | grep -vE "(LISTEN|TIME-WAIT|ESTAB.*sshd)"



**Блокировка IP с помощью [[iptables]] (защита от перебора паролей):**
>#!/bin/bash  
bad_ip="192.168.1.100"  
iptables -A INPUT -s badip−jDROPecho"badi​p−jDROPecho"bad_ip заблокирован" >> /var/log/security.log

## 🔗 Связи

- [[Bash]] — оболочка, исполняющая скрипты.
- [[cron]] — планировщик для автоматического запуска скриптов.
- [[chmod]] — дать скрипту право на выполнение.
- [[Командная строка]] — все команды, которые можно использовать в скриптах.

## 🧠 Значимость для меня как специалиста по ИБ

- Я знаю, что скрипты — это не «удел программистов», а рабочий инструмент, который экономит часы при аудите и расследовании.
- Я могу написать простой скрипт для проверки прав или сбора улик и запустить его вручную или через [[cron]].
- Я понимаю, что скрипты уменьшают влияние человеческого фактора: один раз написанный и проверенный скрипт не допустит опечатку в `rm -rf`.

## ❓ Самопроверка

1. **С чего начинается любой Bash-скрипт?**
   👉 С шебанга: `#!/bin/bash`
2. **Как сделать файл со скриптом исполняемым?**
   👉 `chmod +x имя_скрипта.sh`
3. **Зачем нужны скрипты специалисту по ИБ?**
   👉 Чтобы автоматизировать повторяющиеся проверки (права, порты, логи) и исключить ошибки ручного ввода.
