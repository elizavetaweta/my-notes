# 🚪 Шлюз по умолчанию (Default Gateway)

> [!abstract] Суть одной фразой
> Шлюз по умолчанию — это [[Маршрутизатор (Router)|маршрутизатор]] в локальной сети, на который устройство отправляет все пакеты, предназначенные для адресов, не принадлежащих его собственной подсети. Проще говоря, это «дверь наружу» из локальной сети в интернет или другую сеть.

---

## 📌 Как это работает

1. Устройство (например, ноутбук) формирует пакет для адреса `8.8.8.8`.
2. Оно проверяет, принадлежит ли `8.8.8.8` той же подсети, что и оно само (используя [[Маска подсети (Subnet Mask) и деление на подсети|маску подсети]]).
3. Если нет — пакет отправляется на MAC-адрес шлюза по умолчанию.
4. Шлюз (маршрутизатор) принимает пакет и передаёт его дальше в соответствии со своей таблицей маршрутизации.

Без настроенного шлюза устройство может общаться только с хостами в своём локальном сегменте.

---

## 🔗 Связи

- [[Маршрутизатор (Router)]] — устройство, выполняющее роль шлюза.
- [[Маршрутизация (Routing)]] — процесс, который начинается со шлюза.
- [[IP-адрес]], [[MAC-адрес]] — адреса, используемые для отправки пакета шлюзу.

---

## 💬 Ответ на собеседовании (кратко)

> «Шлюз по умолчанию — это маршрутизатор, через который устройство выходит в другие сети. Я проверяю правильность шлюза через `ip route` и понимаю, что подмена шлюза (MITM) — классическая атака».

## ❓ Самопроверка

1. **Куда отправляется пакет, если адрес получателя находится вне локальной подсети?** 👉 На шлюз по умолчанию.
2. **Как посмотреть шлюз по умолчанию в Linux?** 👉 `ip route | grep default`
