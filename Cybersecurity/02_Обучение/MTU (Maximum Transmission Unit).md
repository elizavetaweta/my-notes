# 📏 MTU (Maximum Transmission Unit)

> [!abstract] Суть одной фразой
> MTU — это максимальный размер полезной нагрузки (payload), которую можно передать через конкретный канальный протокол без фрагментации. Для Ethernet стандартный MTU составляет 1500 байт. Если пакет превышает MTU, он либо фрагментируется, либо отбрасывается с отправкой ICMP-сообщения.

---

## 📌 Зачем нужно знать MTU

- **Производительность.** Фрагментация увеличивает накладные расходы и замедляет передачу.
- **VPN и туннели.** Инкапсуляция добавляет свои заголовки, уменьшая доступное место для полезной нагрузки. Неправильно настроенный MTU может приводить к потере пакетов.
- **Диагностика.** Команда `ping -M do -s <размер>` позволяет проверить, проходит ли пакет без фрагментации.

---

## 🔗 Связи

- [[Фрагментация IP-пакетов]] — процесс, вызванный превышением MTU.
- [[Ethernet]], [[Wi-Fi (беспроводные сети)]] — технологии с разными значениями MTU.
- [[ICMP (Internet Control Message Protocol)]] — протокол, возвращающий ошибку при необходимости фрагментации.
