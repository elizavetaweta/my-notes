# 🗺️ realpath — получение абсолютного пути

> [!abstract] Суть одной фразой
> `realpath` — это команда, которая преобразует относительный путь в **полный (абсолютный)**, начиная от корня файловой системы. Для специалиста по ИБ это инструмент для точного указания местоположения файлов в скриптах и отчётах, исключающий ошибки навигации.

---

## 📌 Базовое использование

> realpath Quarantine/malware

Если ты находишься в `/home/shadowbunny`, команда выведет:
`/home/shadowbunny/Quarantine/malware`

> realpath ../../etc/passwd

Выведет `/etc/passwd`, независимо от текущей директории.

> realpath -m /несуществующий/путь

- `-m` (**m**issing) — показать путь, даже если папок ещё нет (полезно при планировании структуры).

---

## 🕵️ Примеры для специалиста по ИБ

**Сохранение точного пути к улике в отчёте:**

> echo "Образец найден в: $(realpath /tmp/suspicious)" >> evidence.log

**Проверка, куда ведёт символическая ссылка:**

> realpath /etc/alternatives/editor

Покажет реальный путь к исполняемому файлу, а не к ссылке.

## 🧠 Значимость для меня как специалиста по ИБ

- Я знаю, что `realpath` избавляет от путаницы с относительными путями, особенно в скриптах, которые могут запускаться из разных папок.
- Я использую `realpath` для документирования точного расположения файлов при расследовании инцидентов.
