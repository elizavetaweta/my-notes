# 🏠 Локальная сеть (Local Area Network, LAN, Локальная Вычислительная Сеть, ЛВС)

> [!abstract] Суть одной фразой
> Локальная сеть — это объединение устройств на ограниченной территории (офис, этаж, здание) для обмена данными и совместного доступа к ресурсам (файлам, принтерам, интернету).
>  Устройства в LAN обмениваются данными напрямую, без маршрутизаторов, используя [[MAC-адрес|MAC-адреса]] и протоколы канального уровня ([[Ethernet]], [[Wi-Fi (беспроводные сети)]]). Для специалиста по ИБ LAN — это первый рубеж обороны, где применяются [[VLAN]]-сегментация, контроль доступа на [[Коммутатор (Switch)|коммутаторах]] и мониторинг трафика.

---

## 📌 Ключевые признаки LAN

- **Ограниченный масштаб:** одна комната, этаж, здание.
- **Высокая скорость передачи:** от 100 Мбит/с до 100 Гбит/с и выше (современные Ethernet-стандарты).
- **Низкая задержка:** обычно менее 1 мс.
- **Частные IP-адреса:** устройства внутри LAN используют адреса из диапазонов `192.168.x.x`, `10.x.x.x`, `172.16.x.x–172.31.x.x`, которые не маршрутизируются в интернете напрямую.
- **Широковещательный домен:** все устройства в одной LAN (без VLAN) получают широковещательные кадры, что используется протоколами [[ARP (Address Resolution Protocol)|ARP]] и [[DHCP (Dynamic Host Configuration Protocol)|DHCP]]. С точки зрения безопасности это означает, что злоумышленник внутри сегмента может прослушивать широковещательный трафик.

---

## 🆚 LAN vs WAN (глобальная сеть)

| Характеристика | LAN | WAN (Wide Area Network) |
|---|---|---|
| **Масштаб** | Здание, офис, кампус | Город, страна, весь мир |
| **Скорость** | Высокая (Гбит/с) | Ниже (Мбит/с – Гбит/с) |
| **Задержка** | < 1 мс | 10–300 мс |
| **Управление** | Организация владеет оборудованием | Провайдеры владеют каналами |
| **Адресация** | MAC-адреса (L2) + частные IP | Публичные IP-адреса |
| **Устройства** | Коммутаторы, точки доступа | Маршрутизаторы, BGP-пиры |

## 🔧 Устройства и технологии LAN

- **[[Коммутатор (Switch)]]** — основное устройство L2, передающее кадры адресно.
- **[[Концентратор (Hub)]]** — устаревшее устройство, передающее кадры всем портам (работает как общая среда, удобна для злоумышленника).
- **[[Точка доступа (Access Point)]]** — обеспечивает подключение по [[Wi-Fi]].
- **[[Сетевая карта]] (NIC)** — физический интерфейс устройства.
- **Кабельная система:** витая пара (Cat5e, Cat6), оптоволокно.

## 🛠️ Практические инструменты для анализа LAN

Эти команды помогут изучить текущее состояние локальной сети и выявить аномалии.

- **Просмотр ARP-таблицы** (кэш соответствий IP ↔ MAC):
  ```bash
  arp -a                 # Linux/Windows: показать ARP-таблицу
  ip neigh               # Linux: альтернативный просмотр соседей
  ```
- **Поиск активных хостов без сканирования портов** (пинг-разведка):
  ```bash
  nmap -sn 192.168.1.0/24
  ```
  `-sn` (**s**can, **n**o port scan) — отправляет ICMP Echo Request, TCP SYN на порт 443, TCP ACK на порт 80 и ARP-запросы для локальных сетей, определяя активные устройства без полного сканирования портов.
- **Захват ARP-трафика в реальном времени** (обнаружение ARP-спуфинга):
  ```bash
  tcpdump -i eth0 arp
  ```
  `-i eth0` (**i**nterface) — прослушивать интерфейс `eth0`; `arp` — фильтр, показывающий только кадры протокола ARP. Нормальное поведение — запросы и ответы, а частое появление gratuitous ARP или дублирование IP-адресов с разными MAC подозрительно.
- **Проверка текущих сетевых соединений и слушающих портов** (локальный ауст):
  ```bash
  ss -tuln
  ```
  `-t` (**t**cp), `-u` (**u**dp), `-l` (**l**istening), `-n` (**n**umeric) — показать все TCP и UDP сокеты в состоянии прослушивания, не преобразовывая адреса в имена.

## 🛡️ Значимость для специалиста по ИБ

- **Контроль доступа на портах коммутатора:** настраивается **Port Security** — ограничение количества MAC-адресов на порту, привязка конкретного MAC, автоматическая блокировка при нарушении. Это защищает от несанкционированного подключения устройств.
- **Сегментация:** с помощью [[VLAN]] изолируются критичные системы (серверы, бухгалтерия) от гостевых или публичных сетей. Каждая VLAN образует отдельный широковещательный домен, что ограничивает распространение сетевых атак.
- **Мониторинг трафика:** порт коммутатора настраивается как SPAN (порт зеркалирования), через который весь трафик передаётся на IDS/IPS для анализа сигнатур и аномалий.
- **Защита от ARP-спуфинга:** классическая атака в LAN, при которой злоумышленник отправляет поддельные ARP-ответы, связывая свой MAC с IP-адресом шлюза или жертвы. На коммутаторах включается **Dynamic ARP Inspection (DAI)** — проверка ARP-пакетов на соответствие легитимной привязке в DHCP Snooping Binding Table.
- **Обнаружение подозрительной активности:** скрипты мониторинга ARP-таблиц (`arpwatch`, ручной анализ через `arp -a` и `ip neigh`) позволяют заметить появление новых MAC-адресов или изменение соответствий.

> «Локальная сеть — это объединение устройств в пределах здания, работающее на основе MAC-адресов и протоколов канального уровня. В LAN высокая скорость, низкая задержка и частная IP-адресация. Для обеспечения безопасности я применяю VLAN-сегментацию, Port Security на коммутаторах, мониторинг ARP-таблиц и Dynamic ARP Inspection для предотвращения спуфинг-атак. При расследовании инцидентов анализирую ARP-кэш, запускаю tcpdump для захвата подозрительных кадров и проверяю неавторизованные устройства через nmap-сканирование».

## ❓ Самопроверка

1. **На каком уровне OSI работает локальная сеть?** 👉 На канальном (L2) и частично на сетевом (L3), поскольку внутри LAN используется IP-адресация для взаимодействия устройств.
2. **Чем LAN принципиально отличается от WAN?** 👉 Масштабом, скоростью, задержкой и типом адресации (MAC и частные IP в LAN vs публичные IP в WAN).
3. **Какие диапазоны IP используются в локальных сетях?** 👉 `192.168.x.x`, `10.x.x.x`, `172.16.x.x–172.31.x.x`.
