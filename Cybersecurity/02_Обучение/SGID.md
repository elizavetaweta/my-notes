# 🎯 SGID (Set Group ID) — запуск от имени группы

> [!abstract] Суть одной фразой
> SGID (Set Group ID) — это специальный бит прав доступа, который может работать в двух режимах: для **исполняемых файлов** он запускает программу от имени группы-владельца, а для **папок** — заставляет все новые файлы наследовать группу папки. В выводе `ls -la` обозначается буквой `s` в позиции выполнения для группы (`-rwxr-sr-x`).

Для специалиста по ИБ SGID-файлы и папки важны при аудите общих ресурсов и поиске нестандартных путей повышения привилегий.

---

## 📌 Как это работает

1.  **Для исполняемых файлов (`-rwxr-sr-x`):** программа запускается с правами **группы-владельца**, а не группы пользователя. Это позволяет временно получить доступ к ресурсам, разрешённым для этой группы.
2.  **Для папок (`drwxr-sr-x`):** все новые файлы и подпапки, создаваемые внутри, наследуют **группу родительской папки**, а не основную группу пользователя. Это удобно для общих каталогов (`/shared/project`), где все файлы должны принадлежать одной группе.

## 🔢 Как задать и найти SGID-файлы

-   **Установить SGID-бит на файл:** `chmod g+s file`
-   **Установить SGID-бит на папку:** `chmod g+s папка`
-   **Числовой формат:** `chmod 2755 file` — 2 в начале означает SGID-бит.
-   **Найти все SGID-файлы:** `find / -type f -perm -2000`
-   **Найти все SGID-папки:** `find / -type d -perm -2000`

## 🕵️ Значимость для специалиста по ИБ

-   Я проверяю SGID-файлы так же, как SUID: нестандартный SGID на исполняемом файле может быть использован для повышения привилегий.
-   При аудите общих папок я проверяю, установлен ли SGID-бит, чтобы гарантировать корректное наследование группы и избежать случайного раскрытия файлов не той группе.

## 💬 Ответ на собеседовании (кратко)

> «SGID-бит на файле запускает его от имени группы-владельца; на папке — заставляет новые файлы наследовать её группу. Ищу SGID-файлы командой `find / -type f -perm -2000`».
