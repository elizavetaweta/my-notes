# 🧩 Скобки в Bash — все виды и их назначение

> [!abstract] Суть одной фразой
> В [[Bash]] существует несколько видов скобок, и каждый решает свою задачу: группировка команд, изоляция процесса, проверка условий, арифметика, подстановка команд. Умение различать их — базовая грамотность специалиста по ИБ, необходимая для чтения и написания скриптов аудита и автоматизации.

---

## 📌 Обзор всех скобок

| Скобки   | Название                   | Что делают                                                                                        | Пример                            |
| -------- | -------------------------- | ------------------------------------------------------------------------------------------------- | --------------------------------- |
| `( )`    | Подоболочка (subshell)     | Запускают команды в **отдельном процессе**. Переменные и `cd` не влияют на родительскую оболочку. | `(cd /tmp && ls)`                 |
| `{ }`    | Группировка команд         | Выполняют команды в **текущей оболочке**. Весь вывод можно направить в один файл.                 | `{ echo "start"; ls; } > out.txt` |
| `[ ]`    | POSIX-условие              | Старый синтаксис проверки условий. Внутри нельзя использовать `&&` и \|\|.                        | `[ -f file ] && echo "exists"`    |
| `[[ ]]`  | Bash-условие               | Современный синтаксис условий. Поддерживает `&&`, \|\|, =~ для регулярных выражений.              | `[[ -f file && -r file ]]`        |
| `$(( ))` | Арифметическая подстановка | Вычисляют целочисленное выражение и возвращают результат.                                         | `echo $((5 + 3))`                 |
| `$( )`   | Подстановка команды        | Выполняют команду и вставляют её вывод в другую команду.                                          | `echo "Дата: $(date)"`            |
|          |                            |                                                                                                   |                                   |

## 🔍 Особый случай: `\( ... \)` — группировка условий в `find`

В команде [[find]] скобки `\( ... \)` используются для группировки условий поиска. Они не имеют отношения к Bash-скобкам `( )` (подоболочка), а являются операторами самой команды `find`. Поскольку `(` и `)` — специальные символы Bash, их необходимо **экранировать** обратным слэшем, чтобы они были переданы `find`, а не обработаны оболочкой.

> find /usr/bin /usr/sbin -type f \( -perm -4000 -o -perm -2000 \)

Здесь `\( ... \)` группирует условия: `-perm -4000` (SUID) **ИЛИ** (`-o`) `-perm -2000` (SGID). Без скобок `find` интерпретировал бы логику иначе из-за приоритета операторов.

| Скобки | Где используются | Назначение |
|---|---|---|
| `\( ... \)` | Внутри команды `find` | Группировка условий поиска |
| `( ... )` | Bash | Подоболочка (subshell) |
| `{ ... }` | Bash | Группировка команд в текущей оболочке |


## 🔍 Подробный разбор

### 1. `( )` — Подоболочка (subshell)

Команды внутри скобок выполняются в **отдельном процессе** (subshell). Это значит:
- `cd` внутри скобок не изменит твою текущую папку после их закрытия.
- Переменные, созданные внутри, не видны снаружи.

> (cd /tmp && ls)   # ты посмотришь содержимое /tmp, но останешься в исходной папке

**Когда использовать:** нужно временно перейти в другую папку или задать переменные, не затронув основное окружение.

---

### 2. `{ }` — Группировка команд

Команды внутри скобок выполняются в **текущей оболочке**. Это значит:
- `cd` внутри скобок **изменит** твою текущую папку.
- Переменные, созданные внутри, останутся доступны после закрытия скобок.

> { cd /tmp; ls; }   # ты перейдёшь в /tmp и останешься там

**Правила записи:**
- После `{` обязательно пробел.
- Перед `}` обязательно `;` или перевод строки.

**Когда использовать:** нужно собрать вывод нескольких команд в один файл или выполнить последовательность команд как единое целое.

---

### 3. `[ ]` vs `[[ ]]` — Условные выражения

Подробнее — в заметке [[Логические операторы и условия в Bash]].

- **`[ ]`** — POSIX-совместимый синтаксис. Ограничен: внутри нельзя использовать `&&` и `||`, нужно применять `-a` и `-o`. Требует пробелов вокруг скобок.
- **`[[ ]]`** — расширенный синтаксис Bash. Поддерживает `&&`, `||`, регулярные выражения (=~). Не требует экранирования `<` и `>`. Рекомендуется для всех новых скриптов.

> [ -f file ] && echo "exists"           # старый стиль
> [[ -f file && -r file ]] && echo "ok"  # новый стиль

---

### 4. `$(( ))` — Арифметическая подстановка

Вычисляет целочисленное математическое выражение и возвращает результат. Поддерживает: `+`, `-`, `*`, `/`, `%`, `**` (степень).

> echo $((5 + 3))         # 8
> echo $((10 / 3))        # 3 (целочисленное деление)
> count=5
> echo $((count + 1))     # 6

**Когда использовать:** счётчики в циклах, расчёт времени, вычисление размеров.

---

### 5. `$( )` — Подстановка команды

Выполняет команду внутри скобок и вставляет её вывод в другую команду. Это основной способ создавать динамические строки и аргументы.

> echo "Сегодня: $(date)"
> echo "Пользователей в системе: $(who | wc -l)"

Подробнее — в заметке [[Подстановки в Bash - переменные, команды и вычисления]]].

## 🧠 Как запомнить

| Мнемоника | Скобки | Суть |
|---|---|---|
| **Круглые — изолируют** | `( )` | Всё внутри живёт своей жизнью, не влияет на снаружи. |
| **Фигурные — объединяют** | `{ }` | Всё внутри — одна большая команда, вывод в один поток. |
| **Квадратные — проверяют** | `[ ]` / `[[ ]]` | Условия, сравнения, проверки файлов. |
| **Доллар-скобки — вычисляют** | `$(( ))` | Арифметика. |
| **Доллар-круглые — вставляют** | `$( )` | Подстановка вывода команды. |

## ❓ Самопроверка

1. **Чем `( )` отличается от `{ }`?**  
   👉 `( )` — изолированный процесс (subshell), `cd` внутри не меняет текущую папку. `{ }` — группировка в текущей оболочке, `cd` внутри изменит папку.
2. **Как объединить вывод трёх команд в один файл?**  
   👉 `{ команда1; команда2; команда3; } > файл`
3. **Как вычислить сумму двух чисел в Bash?**  
   👉 `echo $((число1 + число2))`
4. **Какой синтаксис условий предпочтительнее и почему?**  
   👉 `[[ ]]` — он поддерживает `&&`, `||`, регулярные выражения и не требует экранирования.
