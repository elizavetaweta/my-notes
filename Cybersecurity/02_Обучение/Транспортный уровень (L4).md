# 🚚 Транспортный уровень (Transport Layer, L4)

> [!abstract] Суть одной фразой
> Транспортный уровень — это четвёртый уровень [[Модель OSI  (Open Systems Interconnection)|модели OSI]], который отвечает за **надёжность доставки данных** между приложениями на разных хостах. Он разбивает поток данных на сегменты (TCP) или датаграммы (UDP), добавляет номера портов и управляет подтверждением получения.

Для специалиста по ИБ это критичный уровень: здесь работают файрволы, происходит сканирование портов и выполняются атаки типа SYN‑flood.

---

## 📌 Что происходит на L4

- Данные с прикладного уровня разбиваются на блоки, готовые к отправке.
- Добавляется **номер порта** отправителя и получателя — именно он позволяет одному хосту обслуживать множество приложений одновременно.
- Протокол TCP добавляет механизмы подтверждения доставки, контроля порядка и перегрузки.
- Протокол UDP жертвует этими механизмами ради скорости.

## 🛡️ Значимость для ИБ

- **Сканирование портов:** злоумышленник определяет открытые службы через TCP SYN‑сканирование (nmap -sS).
- **SYN‑flood:** атака, истощающая ресурсы сервера полуоткрытыми соединениями.
- **UDP amplification:** использование открытых DNS/NTP‑серверов для усиления DDoS.
- **Файрволы:** iptables оперирует на этом уровне, фильтруя по портам (`--dport`, `--sport`).

## ❓ Самопроверка

1. **Какой флаг TCP используется для запроса соединения?** 👉 SYN.
2. **Почему UDP быстрее TCP?** 👉 Не тратит время на handshake и подтверждения.
3. **Как посмотреть слушающие TCP‑порты?** 👉 `ss -tln`.
