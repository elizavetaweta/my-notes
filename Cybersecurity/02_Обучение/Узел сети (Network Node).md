# 🔀 Узел сети (Network Node)

> [!abstract] Суть одной фразой  
> Узел сети — любое устройство, подключённое к сети и способное отправлять, принимать или пересылать данные. Это может быть конечное устройство (компьютер, сервер, телефон) или промежуточное оборудование (маршрутизатор, коммутатор, точка доступа). Каждый узел имеет уникальный идентификатор на своём уровне: [[MAC-адрес]] на канальном (L2), [[IP-адрес]] на сетевом (L3).

В выводе `traceroute` каждый хоп — это отдельный узел сети (маршрутизатор), через который прошёл пакет.

---

## 📌 Типы узлов

- **Конечные узлы (Hosts):** инициируют или завершают передачу данных. Являются источником или конечным получателем трафика. Примеры: ваш ноутбук, [[Сервер (Server)|веб-сервер]], IP-камера.
- **Промежуточные узлы (Intermediary Nodes):** пересылают данные дальше, не являясь их источником или получателем. Обеспечивают связность сети. Примеры: [[Коммутатор (Switch)|коммутатор]], маршрутизатор, точка доступа [[Wi-Fi]].

---

## 🔧 Как идентифицировать узел

- На канальном уровне (L2) — по [[MAC-адрес]]у (физический адрес сетевого интерфейса).
- На сетевом уровне (L3) — по [[IP-адрес]]у (логический адрес, используемый для маршрутизации).
- На прикладном уровне — по доменному имени, разрешаемому через [[DNS (Domain Name System)]].

Базовые утилиты [[ping]] и [[traceroute]] работают именно с IP-адресами узлов.  
Для более глубокого анализа узла в целях информационной безопасности также применяются:

- `ss` / `netstat` — просмотр открытых портов и активных соединений на самом узле;
- `nslookup` / `dig` — проверка привязки доменного имени к IP;
- `nmap` — сканирование портов и определение сервисов (на удалённом узле).

## 🛠️ Практическое исследование узла

### 1. Проверка доступности (ICMP)

```bash
ping -c 4 192.168.1.1
```

Флаг `-c` (**c**ount) задаёт количество отправляемых пакетов (здесь 4).  
Утилита помогает быстро понять, отвечает ли узел, и оценить задержку.

### 2. Трассировка маршрута

```bash
traceroute -n 8.8.8.8
```

Флаг `-n` (**n**umeric) отключает разрешение IP-адресов в доменные имена, ускоряя вывод.  
Показывает все промежуточные узлы (маршрутизаторы) на пути к цели.

### 3. Анализ слушающих портов на локальном узле

```bash
ss -tuln
```

Расшифровка флагов (вне блока кода):  
- `-t` (**t**cp) — показать TCP-сокеты.  
- `-u` (**u**dp) — показать UDP-сокеты.  
- `-l` (**l**istening) — только слушающие (открытые) порты.  
- `-n` (**n**umeric) — не преобразовывать IP-адреса и номера портов в имена (ускоряет вывод).

Команда выводит список локальных портов, на которых сервисы ожидают входящие подключения. Это критически важно для аудита поверхности атаки: вы видите, какие приложения доступны по сети, и можете проверить, не открыты ли лишние или подозрительные порты.

### 4. Разрешение имени узла

```bash
nslookup example.com
```

Возвращает IP-адрес(а), связанные с доменным именем, помогая идентифицировать узел на прикладном уровне.

## 🔒 Значение для информационной безопасности

- **Поверхность атаки** — каждый открытый порт на узле представляет потенциальный вектор атаки. Регулярная проверка слушающих портов (`ss -tuln`) и сканирование периметра (`nmap`) являются базовыми практиками.
- **Идентификация доверенных/недоверенных узлов** — по IP-, MAC-адресам и доменным именам вы определяете, какой трафик разрешён, а какой должен быть заблокирован.
- **Обнаружение аномалий** — внезапное появление нового узла в сети или нестандартного открытого порта может свидетельствовать о компрометации.
- **Трассировка** помогает выявить неавторизованные промежуточные узлы или нештатные маршруты.
- **Защита канального уровня** — фильтрация по MAC-адресам, контроль доступа к портам коммутатора (Port Security) препятствуют подключению неавторизованных устройств.

## 🔗 Связи с другими понятиями

- [[traceroute]] — показывает список промежуточных узлов на пути.
- [[ping]] — проверяет доступность конечного узла.
- [[IP-адрес]], [[MAC-адрес]] — идентификаторы узла.
- [[Маршрутизация (Routing)]] — процесс выбора следующего узла для передачи пакета.
- [[Сканирование портов (Port Scanning)]] — метод исследования узла на наличие открытых портов.
- [[DNS (Domain Name System)]] — система, связывающая доменные имена с IP-адресами узлов.
