# 🌐 Сетевые технологии (контекст специалиста по ИБ)

> [!abstract] Суть одной фразой
> Сетевые технологии — это фундамент, на котором строится взаимодействие компьютеров и передача данных. Для специалиста по ИБ понимание сетей — не просто знание протоколов, а умение анализировать трафик, выявлять аномалии, настраивать защиту и расследовать инциденты на сетевом уровне.

Без сетей нет интернета, нет облаков, нет VPN и нет большинства атак. Ты не сможешь защитить то, чего не видишь и не понимаешь.

---

## 📌 Ключевые понятия

### 1. [[IP-адрес]] (Internet Protocol Address)
Уникальный числовой идентификатор устройства в сети. Как почтовый адрес для компьютера.

- **IPv4:** `192.168.1.10` — 32 бита (четыре числа от 0 до 255). Самый распространённый формат, но адресов уже не хватает (~4.3 млрд).
- **IPv6:** `fe80::a00:27ff:fe4f:abcd` — 128 бит (восемь групп по четыре шестнадцатеричные цифры). Огромное адресное пространство, постепенно вытесняет IPv4.

Для специалиста по ИБ IP-адрес — это первая зацепка при расследовании: кто и откуда подключался, куда стучался злоумышленник.

### 2. [[MAC-адрес]] (Media Access Control)
Уникальный физический «серийный номер» сетевой карты, присвоенный производителем. Например: `08:00:27:ab:cd:ef`.

Работает на канальном уровне (L2 модели OSI). Используется для взаимодействия устройств в пределах одной локальной сети. При атаках типа ARP-spoofing злоумышленник подменяет MAC-адрес, чтобы перехватывать трафик.

### 3. [[Порт (сетевой)]]
Числовой идентификатор конкретного приложения или службы на хосте. Позволяет одному IP-адресу обслуживать несколько сервисов одновременно.

- `22` — SSH.
- `80` / `443` — HTTP / HTTPS.
- `53` — DNS.

При аудите ты всегда проверяешь открытые порты (`ss -tuln`) — каждый лишний порт это потенциальный вектор атаки.

### 4. [[Протокол]]
Набор правил, по которым устройства обмениваются данными. Основные протоколы:

- **TCP (Transmission Control Protocol):** надёжный, с установкой соединения и подтверждением доставки. Используется для HTTP, SSH, FTP.
- **UDP (User Datagram Protocol):** быстрый, без подтверждения доставки. Используется для DNS, VoIP, стриминга.
- **ICMP (Internet Control Message Protocol):** служебные сообщения (ping, traceroute).

### 5. [[Межсетевой экран (Firewall)]]
Система фильтрации сетевого трафика по заданным правилам. Может быть аппаратным, программным ([[iptables]], nftables) или облачным.

Основная задача — пропускать только разрешённый трафик и блокировать всё остальное. Ты настраиваешь правила и проверяешь, не открыты ли лишние порты.

### 6. [[VPN]] (Virtual Private Network)
Технология создания защищённого канала через небезопасную сеть (интернет). Весь трафик шифруется, и злоумышленник не может его прочитать даже при перехвате.

- **[[WireGuard]]** — современный, быстрый, минималистичный.
- **OpenVPN** — более старый, но гибкий.
- **IPsec** — часто используется в корпоративных сетях.

## 🔧 Инструменты специалиста по ИБ (что уже изучено)

- **[[Стек протоколов TCP/IP]]** — управление IP-адресами, маршрутами и ARP-таблицей.
- **[[ss]]** — аудит открытых портов и сетевых соединений.
- **[[tcpdump]]** — перехват и анализ сетевого трафика.
- **[[iptables]]** — настройка встроенного межсетевого экрана.
- **[[ping]]** — базовая проверка доступности хоста.
- **[[nmap]]** — сканирование портов и определение сервисов (продвинутый инструмент).

---

## 🔗 Связи

- **[[Модель OSI]]** — теоретическая основа, на которой построены все сети.
- **[[Стек протоколов TCP/IP]]** — стек протоколов, на котором работает интернет.
- **[[DNS]]** — система доменных имён, переводящая имена в IP-адреса.
- **[[ARP]]** — протокол, связывающий IP и MAC-адреса.
- **[[DHCP]]** — автоматическое назначение IP-адресов.
- **[[TLS]]** — шифрование трафика на прикладном уровне.

## 🔁 Вопросы для закрепления (самопроверка)

- **Вопрос:** Чем TCP отличается от UDP?  
  **Ответ:** TCP — надёжный, с установкой соединения и подтверждением доставки; UDP — быстрый, без подтверждения.

- **Вопрос:** Что такое порт и почему его нужно проверять при аудите?  
  **Ответ:** Порт — идентификатор службы. Открытый порт — это потенциальный вход для злоумышленника.

- **Вопрос:** Какой инструмент используется для аудита открытых портов?  
  **Ответ:** `ss -tuln` — показывает все слушающие TCP/UDP порты.

- **Вопрос:** В чем основное различие между IPv4 и IPv6 адресами?  
  **Ответ:** IPv4 использует 32 бита (~4.3 млрд адресов), а IPv6 — 128 бит (практически неисчерпаемый запас).

- **Вопрос:** На каком уровне модели OSI работает MAC-адрес?  
  **Ответ:** На канальном уровне (L2). Он идентифицирует устройства в пределах одной локальной сети.

- **Вопрос:** Какой протокол автоматически назначает IP-адреса устройствам в сети?  
  **Ответ:** DHCP (Dynamic Host Configuration Protocol).

- **Вопрос:** Что такое ARP-спуфинг и чем он опасен?  
  **Ответ:** Атака, при которой злоумышленник подменяет MAC-адрес, чтобы перенаправить трафик через свою машину и перехватить данные.

- **Вопрос:** Для чего используется протокол ICMP?  
  **Ответ:** Для служебных сообщений (ping, traceroute) и диагностики сети.

- **Вопрос:** Что такое WireGuard и как он обеспечивает безопасность?  
  **Ответ:** Современный протокол VPN, который создаёт защищённый канал, шифруя весь трафик, проходящий через небезопасную сеть.

- **Вопрос:** Какова основная задача межсетевого экрана (Firewall)?  
  **Ответ:** Фильтровать сетевой трафик по заданным правилам, пропуская легитимный и блокируя остальное.

- **Вопрос:** В чем разница между IP-адресом и MAC-адресом?
