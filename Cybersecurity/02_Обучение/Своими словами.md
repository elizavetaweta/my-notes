Модель OSI (Open Systems Interconnection, Модель взаоимдействия открытых систем) - это эталонная сетевая модель, которая разделяет процесс сетевого взаимодействия на 7 логическихх уровней:
Физический - отвечает за передачу битов (нули и единицы) по физической среде (через кабели и радиосигналы). К физическому уровню относят например оптоволокно, Ethernet (витая пара), Wi-Fi радиосигнал, Bluetooth.

Канальный - отвечает за передачу данных внутри одной локальной сети. На этом уровне формируется кадр с MAC-адресом отправителя и получителя, а затем отправляется по сети. К данному уровню относится Ethernet (802.3), Wi-Fi (802.11), ARP (?)

Сетевой - отвечает за маршрутизацию сетевых пакетов между различными сетями по IP-адресам. Помогает выбрать наиболее оптимальный путь для передачи данных.
