Модель OSI (Open Systems Interconnection, Модель взаоимдействия открытых систем) - это эталонная сетевая модель, которая разделяет процесс сетевого взаимодействия на 7 логическихх уровней:
Физический - отвечает за передачу битов (нули и единицы) по физической среде (через кабели и радиосигналы). К физическому уровню относят например оптоволокно, Ethernet (витая пара), Wi-Fi радиосигнал, Bluetooth.

Канальный - отвечает за передачу данных внутри одной локальной сети. На этом уровне формируется кадр с MAC-адресом отправителя и получителя, а затем отправляется по сети. К данному уровню относится Ethernet (802.3), Wi-Fi (802.11), ARP (?)

Сетевой - отвечает за маршрутизацию сетевых пакетов между различными сетями по IP-адресам. Помогает выбрать наиболее оптимальный путь для передачи данных.
К данному уровню относят IP, IPsec.

Транспортный - отвечает за надежную (TCP - Transmission Control Protocol) или быструю (UDP - User Datagram Protocol) передачу данных между приложениями. 
В этом уровне данные разбиваются на сегменты (TCP) или датаграммы (UDP), указываются номера портов и обеспечивается подтверждение доставки (TCP)

Сеансовый - обеспечивает создание, поддержание и завершение сеасов связи между приложениями.

Представления - отвечает за преобразование данных в понятную для прикладных процессов форму. Сюда относится шифрование, сжатие и кодирование данных.
К этому уровню относится TLS\SSL, JPEG, ASCII.

Прикладной - отвечает за взаимодейтсвие пользователя и сети. Предоставляет интерфейс для сетевых приложений.
Суть данного уровня - передать для сети команду при помощи понятного для нее протокола.
Пример: HTTP, HTTPS, DNS, DHCP.

Для специалиста по ИБ модель OSI важный практический инструмент диагностики. Понимая на каком уровне реализиуется атака или сбой, можно легко понять где искать улики и как строить защиту.

Порт - это числовой идентификатор, который указывает операционной системе какому именно приложению или службе передавать входящий сетевой пакет.

IP адрес - это идентификатор устройства, подключенного к локальной сети или интернету.

IP-адресация - это система идентификации устройства в сети на основе его IP-адреса.

MAC-адрес - это уникальный идентификатор, который присваивает производитель сетевому интерфейсу устройства.

Кадр - это единица передачи данных на канальном уровне. 
Кадр состоит из преамбулы (битов), заголовка (MAC-адрес отправителя и получателя), Полезной нагрузки (Payload, включает в себя IP-пакет), Трейлера (концевика, включает в себя контрольную сумму).

ARP (Adress Resolution Protocol) - это протокол, который позволяет определить MAC-адреса устройства при помощи IP-адреса устройства.
