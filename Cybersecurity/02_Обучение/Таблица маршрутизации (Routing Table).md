# 🗺️ Таблица маршрутизации (Routing Table)

> [!abstract] Суть одной фразой
> Таблица маршрутизации — это база данных, хранящаяся в оперативной памяти [[Маршрутизатор (Router)|маршрутизатора]] или конечного узла, которая определяет, на какой следующий узел (Next Hop) и через какой интерфейс отправлять [[Пакет (сетевой)|пакеты]] для каждой известной сети назначения. Это фундамент [[Маршрутизация (Routing)|маршрутизации]].

---

## 📌 Структура записи (упрощённо)

Каждая запись содержит:
- **Сеть назначения (Destination):** IP-префикс, например `192.168.1.0/24`.
- **Шлюз (Next Hop):** адрес следующего маршрутизатора, которому нужно передать пакет. Для непосредственно подключённых сетей шлюз может быть не указан.
- **Интерфейс (Interface):** локальный сетевой интерфейс (eth0, wlan0), через который отправлять пакет.
- **Метрику (Metric):** числовая оценка «стоимости» маршрута, используется для выбора лучшего пути.

Просмотреть таблицу в Linux: `ip route show`.

---

## 🔗 Связи

- [[Маршрутизация (Routing)]], [[Маршрутизатор (Router)]] — устройства и процесс, использующие таблицу.
- [[Шлюз по умолчанию (Default Gateway)]] — запись по умолчанию в таблице.
- [[BGP (Border Gateway Protocol)]], [[OSPF]] — протоколы, которые автоматически наполняют таблицу маршрутизации.

## 💬 Ответ на собеседовании (кратко)

> «Таблица маршрутизации хранит правила пересылки пакетов: сеть назначения → следующий узел → интерфейс. Я смотрю её через `ip route show`. Статические записи добавляются вручную, динамические — протоколами маршрутизации».

## ❓ Самопроверка

1. **Что означает запись `default via 192.168.1.1 dev eth0`?** 👉 Все пакеты, для которых нет явного маршрута, отправлять через шлюз 192.168.1.1 на интерфейсе eth0.
2. **Чем статическая запись в таблице отличается от динамической?** 👉 Статическая вносится администратором, динамическая — протоколом маршрутизации.
