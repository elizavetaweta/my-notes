# 📜 Протокол (сетевой)

> [!abstract] Суть одной фразой
> Протокол — это набор правил, по которым устройства договариваются о формате и порядке обмена данными. Как дипломатический этикет, но для компьютеров. Для специалиста по ИБ знание протоколов — это умение читать трафик, находить аномалии и настраивать фильтрацию.

---

## 📌 Основные протоколы

- **TCP (Transmission Control Protocol):** надёжный, с подтверждением доставки. Используется для HTTP, SSH, FTP.
- **UDP (User Datagram Protocol):** быстрый, без подтверждения. DNS, VoIP, стриминг.
- **ICMP (Internet Control Message Protocol):** служебные сообщения (`ping`, ошибки доставки).
- **HTTP/HTTPS:** протоколы передачи веб-страниц.
- **DNS:** перевод доменных имён в IP-адреса.
- **ARP:** связывание IP и MAC в локальной сети.

---

## 🕵️ Значимость для ИБ

- Анализ трафика (`tcpdump`) позволяет увидеть аномалии на уровне протоколов.
- Атаки используют особенности протоколов: ARP-spoofing, DNS-spoofing, SYN-flood (TCP), amplification (UDP).
- Настройка `iptables` требует указания протокола (`-p tcp`, `-p udp`).

## ❓ Самопроверка

1. **Чем TCP отличается от UDP?** 👉 TCP с подтверждением, UDP — без.
2. **Какой протокол использует ping?** 👉 ICMP.
