# 🔐 Обозначение прав доступа в Linux

> [!abstract] Суть одной фразой
> Права доступа в [[Linux]] определяют, кто может читать, изменять и запускать файлы и папки. Они записываются в двух форматах — символьном (`rwx`) и числовом (восьмеричном, `755`). Для специалиста по ИБ умение читать и находить файлы с аномальными правами — один из главных навыков аудита.

---

## 📌 Символьная запись (буквенная)

В выводе `ls -la` права отображаются строкой из 10 символов, например `-rwxr-xr--`.

| Позиция | Пример | Значение |
|---|---|---|
| 1 | `-` | Тип файла: `-` — обычный, `d` — папка, `l` — ссылка |
| 2–4 | `rwx` | Права **владельца** (user): чтение (r), запись (w), выполнение (x) |
| 5–7 | `r-x` | Права **группы** (group) |
| 8–10 | `r--` | Права **остальных** (others) |

> [!note] Типы файлов
> Подробнее о первом символе (`-`, `d`, `l`, `b`, `c`, `s`, `p`) — в заметке [[Типы файлов в Linux]].

---

## 🔢 Числовая (восьмеричная) запись

Каждой группе прав соответствует сумма трёх битов:

| Бит | Значение | Символ |
|---|---|---|
| **4** | Чтение | `r` |
| **2** | Запись | `w` |
| **1** | Выполнение | `x` |
| **0** | Нет права | `-` |

Три цифры задают права для **владельца**, **группы** и **остальных**:

| Число | Символы | Смысл |
|---|---|---|
| `7` = 4+2+1 | `rwx` | Чтение, запись, выполнение |
| `6` = 4+2 | `rw-` | Чтение и запись |
| `5` = 4+1 | `r-x` | Чтение и выполнение |
| `4` = 4 | `r--` | Только чтение |
| `0` = 0 | `---` | Ничего нельзя |

**Примеры:**

> chmod 755 script.sh   # rwxr-xr-x
> chmod 600 private.key # rw-------
> chmod 644 config.txt  # rw-r--r--

## ⚙️ Специальные биты (четвёртая цифра)

Перед тремя основными цифрами может стоять четвёртая — она кодирует специальные биты:

| Бит | Значение | Где видно | Команда поиска |
|---|---|---|---|
| **4** — SUID | Файл запускается от имени **владельца** | `-rwsr-xr-x` | `find / -type f -perm -4000` |
| **2** — SGID | Файл запускается от имени **группы**; на папке — файлы наследуют группу | `-rwxr-sr-x` | `find / -type f -perm -2000` |
| **1** — Sticky | Удалять файлы из папки может только владелец (например, `/tmp`) | `drwxrwxrwt` | `find / -type d -perm -1000` |

> [!note] Как задать
> `chmod 4755 file` — SUID + rwxr-xr-x.  
> `chmod 2755 file` — SGID + rwxr-xr-x.  
> `chmod 1777 dir`  — Sticky + rwxrwxrwx.

## 📌 Кто есть кто

| Символ | Категория | Английское название | Кто попадает в эту категорию |
|---|---|---|---|
| `u` | Владелец | **U**ser | Пользователь, которому принадлежит файл (обычно тот, кто его создал). |
| `g` | Группа | **G**roup | Все пользователи, входящие в группу-владельца файла. |
| `o` | Остальные | **O**thers | Все остальные пользователи системы, не являющиеся владельцем и не входящие в группу. |
| `a` | Все | **A**ll | Сокращение для `ugo` — все три категории одновременно. |

## 🔧 Где применяются

### 1. `chmod` — изменение прав доступа

Символьный режим `chmod` позволяет добавлять или убирать права у конкретных категорий:

> chmod u+x script.sh     # дать владельцу право на выполнение
> chmod g-w file.txt      # запретить группе запись в файл
> chmod o-r file.txt      # запретить остальным читать файл
> chmod a=r file.txt      # всем только чтение (сбросить остальные права)

### 2. `find` — поиск файлов по принадлежности

> find /home -user alice        # найти файлы, принадлежащие пользователю alice
> find /var/www -group www-data # найти файлы, принадлежащие группе www-data

### 3. `stat` и `ls` — просмотр владельца и группы

> stat file.txt    # показывает Uid и Gid (числовой и текстовый)
> ls -la           # колонки с именем владельца и группы

## 🕵️ Поиск файлов по правам (аудит)

- **SUID-файлы (потенциальная эскалация):** `find / -type f -perm -4000`
- **SGID-файлы:** `find / -type f -perm -2000`
- **Файлы, доступные всем на запись:** `find / -type f -perm -o+w`
- **Файлы с правами 777:** `find / -type f -perm 0777`

Флаг `-` перед числом означает поиск **по маске**: проверяется только наличие указанного бита, остальные права игнорируются. Без минуса — точное совпадение всех 12 битов.


## 🎯 Три режима работы `-perm`: префиксы `-` и `/`

Тест `-perm` в команде [[find]] ищет файлы по правам, но его поведение зависит от префикса:

| Режим                                   | Запись         | Что означает                                                                               | Пример       | Что найдёт                                             |
| --------------------------------------- | -------------- | ------------------------------------------------------------------------------------------ | ------------ | ------------------------------------------------------ |
| **Точное совпадение**                   | `-perm число`  | Права файла должны **строго совпадать** с указанными                                       | `-perm 644`  | Файлы с правами **ровно** `rw-r--r--`                  |
| **Все указанные биты установлены**      | `-perm -число` | У файла должны быть **как минимум** указанные биты. Префикс `-` (минус) — «не меньше чем». | `-perm -444` | Файлы, у которых **все три категории** имеют право `r` |
| **Любой из указанных битов установлен** | `-perm /число` | У файла должен быть установлен **хотя бы один** из указанных битов. Префикс `/` — «или».   | `-perm /111` | Файлы, которые **кто‑нибудь** может выполнять          |

> [!tip] Как запомнить префиксы
> - **Минус (`-`)** → «как минимум» (≥). Файл должен иметь все указанные биты.
> - **Слэш (`/`)** → «или». Достаточно хотя бы одного из указанных битов.
> - **Без префикса** → «строго равно».

## ❓ Самопроверка

1. **Что означают права `rwxr-xr--`?**  
   👉 Владелец может всё, группа — читать и выполнять, остальные — только читать.
2. **Как найти все SUID-файлы?**  
   👉 `find / -type f -perm -4000`
3. **Чем `-perm 4755` отличается от `-perm -4000`?**  
   👉 `4755` — точное совпадение (SUID + rwxr-xr-x). `-4000` — поиск по наличию SUID-бита, остальные права любые.
