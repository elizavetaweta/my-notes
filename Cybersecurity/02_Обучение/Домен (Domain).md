# 🌐 Домен (Domain)

> [!abstract] Суть одной фразой
> В ИТ у слова «домен» есть два основных значения, и их важно не путать. **Доменное имя (DNS-домен)** — это удобочитаемый адрес сайта в интернете (например, `google.com`). **Домен Windows (Active Directory)** — это централизованная система управления пользователями, компьютерами и политиками в корпоративной сети. Для специалиста по ИБ оба понятия критичны: первое связано с защитой веб-ресурсов и фишингом, второе — с контролем доступа, аудитом и защитой всей ИТ-инфраструктуры.

---

## 📌 Доменное имя (DNS Domain)

Это то, с чем ты сталкиваешься каждый день в браузере: `ya.ru`, `wikipedia.org`, `github.com`.

- Доменное имя нужно для того, чтобы людям было удобно запоминать адреса сайтов. Компьютеры же общаются по [[IP-адрес]]ам, и перевод доменного имени в IP-адрес выполняет [[DNS (Domain Name System)|DNS]].
- Домены организованы в иерархию: есть корневые домены (`.com`, `.org`, `.ru`), домены второго уровня (`google.com`) и поддомены (`mail.google.com`).
- **С точки зрения ИБ:** злоумышленники могут регистрировать фишинговые домены, похожие на настоящие (например, `g00gle.com`), чтобы воровать пароли. Защита домена от захвата — важная задача.

## 🏛️ Домен Windows (Active Directory Domain)

Это не про интернет, а про внутреннюю сеть организации. Домен Windows — это группа компьютеров и пользователей, которыми управляет **контроллер домена (Domain Controller, DC)**.

- **Централизованное управление:** администратор один раз заводит учётную запись пользователя, и она работает на всех компьютерах в домене.
- **Групповые политики (Group Policy):** можно принудительно настроить параметры безопасности на сотнях машин (сложность паролей, блокировка USB-портов, запрет на установку ПО).
- **Аутентификация:** когда ты входишь в систему, твой пароль проверяет не локальный компьютер, а контроллер домена (по протоколу Kerberos).
- **С точки зрения ИБ:** компрометация контроллера домена — одна из самых серьёзных атак. Злоумышленник получает «ключи от всего королевства». Защита Active Directory — отдельное большое направление в ИБ.

---

## 🔗 Связи

- [[DNS (Domain Name System)]] — система, превращающая DNS-домен в IP-адрес.
- [[Active Directory]] — технология, лежащая в основе домена Windows (если будешь делать отдельную заметку).
- [[LDAP]], [[Kerberos]] — протоколы, используемые в домене Windows.
- [[Фишинг]] — атака, часто эксплуатирующая похожие доменные имена.

## 💬 Ответ на собеседовании (кратко)

> «У термина "домен" два значения. DNS-домен — это имя сайта в интернете, которое через DNS преобразуется в IP-адрес. Домен Windows — это централизованная система управления пользователями и политиками в корпоративной сети на базе Active Directory. Я понимаю разницу и знаю, какие угрозы актуальны для каждого из этих понятий: фишинг и захват домена для первого, компрометация контроллера домена — для второго».

## ❓ Самопроверка

1. **Что такое DNS-домен?** 👉 Удобочитаемое имя сайта (например, `example.com`), которое DNS преобразует в IP-адрес.
2. **Что такое домен Windows?** 👉 Группа компьютеров и пользователей, управляемая через контроллер домена с помощью Active Directory.
3. **Какая атака на домен Windows считается самой опасной?** 👉 Компрометация контроллера домена, дающая злоумышленнику полный контроль над сетью.
