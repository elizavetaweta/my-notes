
Для поиска следов сканирования уязвимостей нужно изучить файл /var/log/nginx/access.log. 
Мы ищем строки, содержащие статус ответа " 404 ", чтобы выявить попытки подбора скрытых страниц. 
Затем с помощью awk нужно извлечь IP-адреса атакующих, отсортировать их и подсчитать количество уникальных запросов с каждого адреса.
