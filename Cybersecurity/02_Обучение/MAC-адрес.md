# 🔌 MAC-адрес (Media Access Control)

> [!abstract] Суть одной фразой
> MAC-адрес — это уникальный физический идентификатор сетевого интерфейса, присвоенный производителем. Он работает на канальном уровне модели OSI (L2) и служит для доставки кадров в пределах одного широковещательного домена. Специалисту по ИБ этот адрес позволяет выявлять подмену устройств, фиксировать атаки типа ARP-spoofing и отслеживать активы в сети.

## 📌 Формат, OUI и идентификация производителя

Записывается как шесть пар шестнадцатеричных цифр, разделённых двоеточиями или дефисами, например:  
`08:00:27:ab:cd:ef`

- **OUI (Organizationally Unique Identifier)** — первые три байта (24 бита), которые IEEE закрепляет за конкретным производителем.
- По OUI можно приблизительно определить тип устройства (сетевую карту, точку доступа, виртуальную машину), что полезно при пассивной разведке и инвентаризации.
- Поиск производителя: `maclookup.app`, `Wireshark OUI Lookup`, локально через `arp -a | grep ...` или `ip neigh`.

## 🖥️ Как узнать MAC-адрес

```bash
ip link show                     # современный способ (строка link/ether)
ip addr show                     # также показывает MAC
ifconfig                         # устаревшая, но ещё встречается
arp -a                           # таблица соответствий IP–MAC (ARP-кэш)
ip neigh                         # аналогично, современный инструмент
```
В Windows:
```powershell
ipconfig /all                    # Physical Address
getmac /v                        # список MAC всех адаптеров
```

## 🔑 Ключевые свойства (и мифы)

- **Заводская уникальность** — производитель обязан выпускать интерфейсы с разными MAC. Однако она не гарантирует безопасность: злоумышленник может сменить адрес.
- **Привязка к оборудованию** — адрес сохраняется при перемещении между сетями, в отличие от IP. Но сегодня многие ОС по умолчанию используют случайные MAC при сканировании Wi‑Fi (MAC randomization), что усложняет трекинг.
- **Подмена (spoofing)** — программное изменение MAC загружается в память драйвера после загрузки ОС. На Linux это делается, например, так:
  ```bash
  ip link set dev eth0 address 00:11:22:33:44:55
  ```
  Атака позволяет обходить фильтры, выдавать себя за доверенное устройство или избегать юридической идентификации.

## 🕵️ Значимость для информационной безопасности

### Расследование инцидентов
- MAC фиксируется в логах DHCP, RADIUS, коммутаторов и позволяет сопоставить событие с конкретным «железом».
- При анализе трафика (pcap-файлы) первые три байта указывают производителя и могут сигнализировать о появлении несанкционированного оборудования.

### Типичные атаки канального уровня
- **ARP-spoofing / ARP-poisoning** — подмена MAC-адреса шлюза в ARP-таблице жертвы, перенаправляющая весь трафик через машину атакующего. Классическая атака «человек посередине» (MITM) в локальной сети.
- **MAC flooding** — переполнение таблицы CAM-коммутатора, принуждающее его работать как хаб и рассылать кадры во все порты. Облегчает сниффинг.
- **Обход аутентификации по MAC** — общедоступные Wi‑Fi сети иногда используют MAC‑фильтрацию как единственную защиту; подделав разрешённый адрес, можно подключиться без пароля.

### Защитные меры (с учётом ограничений)
- **Фильтрация по MAC** на маршрутизаторах или точках доступа — **только как дополнение**, потому что адрес легко подделать.
- **Динамическая проверка ARP (DAI)** на управляемых коммутаторах сверяет MAC-IP-привязки с доверенной базой DHCP Snooping и отбрасывает подозрительные ARP-пакеты.
- **Мониторинг ARP-таблиц**:
  ```bash
  watch -n 2 'arp -a'            # периодический просмотр изменений
  arpwatch                        # автоматическое уведомление о новых парах
  ```
  Сравнивайте текущие записи с эталонными списками известных устройств.
- **Статический ARP для критичных хостов** — жёстко прописывается IP–MAC на важных серверах и шлюзе (но трудно масштабируется).
- **Портовый контроль (Port Security)** на коммутаторе ограничивает количество MAC-адресов на порту и блокирует порт при нарушении.

## 🔗 Связи с другими понятиями

- [[Стек протоколов TCP IP]] — через команды `ip link`, `ip neigh` видим MAC; IP-пакеты инкапсулируются в кадры с MAC-адресами.
- [[ARP (Address Resolution Protocol)]] — протокол, разрешающий IP‑адрес в MAC. Главный источник атак канального уровня.
- [[Сетевые технологии]] — место MAC в Ethernet, Wi‑Fi, Bluetooth.
- [[iptables]] — позволяет фильтровать трафик по MAC-адресу источника/назначения (опция `--mac-source`).
- [[NAC (Network Access Control)]] — контроль доступа на основе MAC часто выступает одним из факторов аутентификации.
- [[IDS/IPS]] — некоторые сигнатуры ориентированы на обнаружение аномалий ARP и дублирующихся MAC.

## ❓ Самопроверка

1. **Как быстро вывести MAC-адрес конкретного интерфейса в Linux?** 👉 `ip link show eth0`
2. **Чем опасен ARP-spoofing с точки зрения ИБ?** 👉 Позволяет перехватывать, модифицировать или блокировать трафик жертвы без её ведома.
3. **Почему MAC-фильтрация не является надёжной мерой?** 👉 Адрес можно подделать за секунды одной командой.
4. **Какие инструменты помогают детектировать подмену MAC в реальном времени?** 👉 `arpwatch`, `arpalert`, модули DAI на коммутаторе.
5. **Что такое MAC randomization и как она влияет на аудит сети?** 👉 Техника смены MAC мобильными устройствами при поиске сетей; затрудняет долговременное отслеживание одного и того же клиента.
