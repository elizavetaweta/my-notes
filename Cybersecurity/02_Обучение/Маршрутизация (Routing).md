# 🧭 Маршрутизация (Routing)

> [!abstract] Суть одной фразой
> Маршрутизация — это процесс выбора оптимального пути для передачи [[Пакет (сетевой)|пакетов]] от отправителя к получателю через промежуточные сетевые узлы ([[Маршрутизатор|маршрутизаторы]]). Решение о маршруте принимается на основе таблиц маршрутизации, которые содержат информацию о доступных сетях и расстоянии до них.

---

## 📌 Как работает маршрутизация

1. Узел-отправитель формирует пакет с IP-адресом назначения.
2. Пакет передаётся на ближайший маршрутизатор (шлюз по умолчанию).
3. Маршрутизатор анализирует адрес назначения и ищет его в своей таблице маршрутизации.
4. Найдя совпадение (или маршрут по умолчанию), маршрутизатор передаёт пакет на следующий узел.
5. Процесс повторяется, пока пакет не достигнет получателя.

Таблицы маршрутизации строятся:
- **Статически** — администратор прописывает маршруты вручную.
- **Динамически** — маршрутизаторы обмениваются информацией по протоколам ([[BGP]], OSPF, RIP).

---

## 🔑 Ключевые понятия

- **Маршрутизатор (Router)** — устройство, соединяющее разные сети и передающее пакеты между ними.
- **Хоп (Hop)** — один переход пакета между двумя маршрутизаторами.
- **TTL (Time To Live)** — счётчик хопов в IP-заголовке. Каждый маршрутизатор уменьшает его на 1. При TTL=0 пакет уничтожается, чтобы он не «блуждал» вечно.
- **Таблица маршрутизации** — база данных на маршрутизаторе, где указано, через какой интерфейс и на какой следующий узел отправлять пакеты для каждой известной сети.

---

## 🔧 Инструменты диагностики

- **[[traceroute]]** — показывает все хопы на пути к цели.
- **[[ping]]** — проверяет доступность конечного хоста.
- **`ip route`** — просмотр локальной таблицы маршрутизации на Linux.

---

## 🔗 Связи

- [[IP-адрес]] — адрес, по которому строится маршрут.
- [[BGP]] — протокол глобальной маршрутизации в интернете.
- [[Маршрутизатор]] — устройство, выполняющее маршрутизацию.
- [[Пакет (сетевой)]] — объект, который маршрутизируется.

## ❓ Самопроверка

1. **Что такое хоп?** 👉 Один переход пакета между двумя маршрутизаторами.
2. **Зачем нужен TTL?** 👉 Чтобы пакет не циркулировал вечно при ошибках маршрутизации.
