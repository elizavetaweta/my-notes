# 🚪 Шлюз (Gateway)

> [!abstract] Суть одной фразой
> Шлюз — это устройство (обычно [[Маршрутизатор (Router)|маршрутизатор]]), которое соединяет две разные IP-сети и передаёт [[Пакет (сетевой)|пакеты]] между ними. В локальной сети шлюз служит «выходом» во внешний мир: все пакеты, предназначенные для адресов за пределами собственной подсети, отправляются на шлюз. Термин «шлюз по умолчанию» (default gateway) обозначает конкретный узел, через который устройство отправляет трафик, если у него нет более точного маршрута.

Для специалиста по ИБ шлюз — критичная точка контроля: здесь настраиваются правила [[Межсетевой экран (Firewall)|файрвола]], трансляция адресов ([[NAT (Network Address Translation)|NAT]]), а подмена шлюза (ARP-spoofing) является одной из классических атак на локальную сеть.

---

## 📌 Как работает шлюз

1. Устройство (ноутбук, сервер) формирует пакет для IP-адреса, находящегося вне его собственной подсети (например, `8.8.8.8`).
2. Используя [[Маска подсети (Subnet Mask) и деление на подсети|маску подсети]], устройство определяет, что адрес назначения — внешний.
3. Пакет отправляется на [[MAC-адрес]] шлюза (определяется через [[ARP (Address Resolution Protocol)|ARP]]), а не на MAC-адрес конечного получателя.
4. Шлюз принимает пакет, анализирует IP-адрес назначения и передаёт его дальше в соответствии со своей [[Таблица маршрутизации (Routing Table)|таблицей маршрутизации]].

---

## 🔑 Шлюз по умолчанию (Default Gateway)

Это частный случай шлюза — маршрут «для всего остального». В таблице маршрутизации запись `default via 192.168.1.1 dev eth0` означает: «все пакеты, для которых нет явного маршрута, отправляй через `192.168.1.1` на интерфейсе `eth0`».

**Как посмотреть:**
> `ip route | grep default`

---

## 🛡️ Значимость для ИБ

- **Контроль трафика:** через шлюз проходит весь межсетевой трафик, поэтому здесь настраиваются списки контроля доступа (ACL), NAT и фильтрация.
- **Обнаружение атак:** если шлюз по умолчанию внезапно изменился, это может указывать на MITM-атаку или компрометацию сети.
- **ARP-spoofing:** злоумышленник подменяет MAC-адрес шлюза, заставляя жертву отправлять трафик через него.

---

## 🔗 Связи

- [[Шлюз по умолчанию (Default Gateway)]] — частный случай, настройка и проверка.
- [[Маршрутизатор (Router)]] — устройство, выполняющее роль шлюза.
- [[Маршрутизация (Routing)]] — процесс, который начинается со шлюза.
- [[NAT (Network Address Translation)]] — технология, работающая на шлюзе.
- [[Межсетевой экран (Firewall)]] — фильтрация на шлюзе.
- [[ARP (Address Resolution Protocol)]] — протокол, через который определяется MAC-адрес шлюза.

## 💬 Ответ на собеседовании (кратко)

> «Шлюз — это устройство, соединяющее разные сети и передающее пакеты между ними. Шлюз по умолчанию — это маршрут «для всего остального», на который отправляются пакеты для внешних адресов. Я проверяю шлюз через `ip route`, понимаю риски подмены шлюза (ARP-spoofing) и настраиваю фильтрацию трафика именно здесь».

## ❓ Самопроверка

1. **Какую роль выполняет шлюз в локальной сети?** 👉 Соединяет локальную сеть с внешними сетями (интернетом), передавая пакеты между ними.
2. **Как посмотреть шлюз по умолчанию в Linux?** 👉 `ip route | grep default`.
3. **Почему подмена шлюза опасна?** 👉 Весь трафик жертвы начинает проходить через злоумышленника, что позволяет перехватывать и модифицировать данные (MITM).
