Адаптация генерации ИИ под разные типы материалов ИБ состоит из принципиально разного контента.
Измените свой подход (и промпты в Companion) в зависимости от темы:
А. Для нормативки (ФЗ-152, КИИ, приказы ФСТЭК/ФСБ) Обычные карточки «Вопрос-Ответ» здесь бесполезны. Просите ИИ делать карточки с пропусками (Cloze, CQ).Пример промпта в Companion: Сделай карточки с пропусками (CQ) по ключевым терминам, штрафам и зонам ответственности из этой заметки.Результат: ИИ скроет критические цифры и определения, которые нужно помнить дословно.
Б. Для командной строки (Linux, tcpdump, nmap, tshark)Здесь критически важен контекст утилит. Просите ИИ использовать поле Context (I | ...).Пример промпта: Создай карточки по флагам командной строки. В поле вопроса (Q) пиши задачу, в ответе (A) — саму команду с флагами, а в поле подсказки (I) — краткое описание, что делает конкретный флаг.
