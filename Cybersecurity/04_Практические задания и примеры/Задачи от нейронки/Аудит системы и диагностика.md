# 🧪 Лабораторная работа №1. Аудит системы и диагностика

> [!abstract] Сценарий
> Ты — специалист по ИБ, который впервые заходит на новый сервер. Твоя задача — собрать базовую информацию о системе: версию ядра, время работы, список пользователей и состояние дисков.

---

## 📋 Задание 1. Системная информация

1. Узнай версию ядра и архитектуру процессора.
2. Запиши их в файл `system_info.txt`.
3. Проверь, как долго сервер работает без перезагрузки, и **допиши** эту информацию в конец того же файла.
4. Посмотри, какое имя хоста у сервера, и тоже добавь его в `system_info.txt`.

Мои команды:
```bash
1. echo $(uname -r) $(uname -m) > system_info.txt
2. uptime -p >> system_info.txt
3. hostname >> system_info.txt
```

Как можно улучшить:
```bash
printf "%s\n" "$(uname -r) $(uname -m)""$(uptime -p)" "$(hostname)" > system_info.txt
```

## 📋 Задание 2. Пользователи и группы

1. Проверь, под какой учётной записью ты сейчас работаешь.
2. Узнай, входит ли твой пользователь в группу `sudo` (или `wheel`).
3. Посмотри, кто ещё из пользователей есть в системе, и запиши их имена в файл `users_list.txt`.

**Мои команды:**
```bash
1. whoami
2. id
3. cut -d ':' -f 1 /etc/passwd > users.txt && cat users.txt
```

## 📋 Задание 3. Дисковая подсистема

1. Узнай, сколько свободного места осталось на корневом разделе (`/`).
2. Найди самую «тяжёлую» папку в каталоге `/var/log`.
3. Запиши её имя и размер в файл `disk_usage.txt`.

Мои команды:

```bash
1. df -h /
2. sudo du -sh /var/log/* | sort -rh | head -1 > disk_usage.txt
```
