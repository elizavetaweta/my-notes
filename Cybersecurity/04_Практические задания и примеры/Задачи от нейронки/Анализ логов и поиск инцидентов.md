# 🧪 Лабораторная работа №2. Анализ логов и поиск инцидентов

> [!abstract] Сценарий
> В файле `/var/log/auth.log` хранятся события аутентификации. Тебе нужно найти следы попыток подбора пароля и вычислить атакующего.

---

## 📋 Задание 1. Поиск неудачных попыток

1. Найди все строки, содержащие `Failed password`.
2. Сохрани их в отдельный файл `failed_attempts.log`.

**Моя команда:**
```bash
journalctl --facility=auth | grep -i "Failed password" > failed_attempts.log
```

Использовала journalctl  так как в Manjaro по умолчанию **нет** традиционных текстовых логов. Вместо них используется **systemd-журнал** — более современная система логирования.
- Вместо файла `/var/log/auth.log` все события аутентификации хранятся в **централизованном журнале systemd**.
- Доступ к этому журналу осуществляется через команду `journalctl`


---

## 📋 Задание 2. Вычисление атакующего

1. Из файла `failed_attempts.log` извлеки только IP-адреса.
2. Подсчитай, сколько попыток было с каждого IP.
3. Найди IP-адрес, с которого было больше всего попыток. Запиши его в файл `top_attacker.txt`.

**Мои команды:**
```bash
1. grep -oP 'from \K[0-9.]+' failed_attempts.log > ip_adresses.txt
   или
   awk '/Failed password/ {print $11}' failed_attempts.log > ip_addresses.txt
   
2. sort ip_adresses.txt | uniq -c | sort -rn | head -n 1 > top_attacker.txt
```

[[grep]] [[sort]] [[uniq]] [[head]]

Что получилось:
Файл `top_attacker.txt` содержит строку:
>8 185.220.101.34

## 📋 Задание 3. Исследование конкретного IP

1. Найди **все** записи (и успешные, и неудачные), связанные с IP-адресом из предыдущего задания.
2. Ищи в **полном** файле `/var/log/auth.log`, а не только в `failed_attempts.log`.
3. Сохрани результат в файл `attacker_full.log`.

Мои команды:

 >[!note] Для Manjaro
> Файл `/var/log/auth.log` отсутствует. Для выполнения задания использован смоделированный файл `auth_full.log`, созданный командой `printf`. 

```bash
grep "185.220.101.34" auth_full.log > attacker_full.log
```
