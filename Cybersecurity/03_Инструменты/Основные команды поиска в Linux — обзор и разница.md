# 🔍 Основные команды поиска в Linux — обзор и разница

> [!abstract] Суть одной фразой
> В [[Linux]] есть несколько команд для поиска, и каждая решает свою задачу. `find` ищет **файлы и папки** по любым атрибутам, `grep` ищет **текст внутри файлов**, `locate` ищет **имена файлов** по готовой базе данных, а `which` и `whereis` — **местоположение исполняемых программ**. Знание разницы позволяет выбрать правильный инструмент за секунду, а не перебирать все подряд.

---

## 📌 Четыре поисковых инструмента — когда что использовать

### 🔍 1. `find` — поиск файлов и папок по атрибутам

**Что ищет:** файлы и каталоги по имени, типу, размеру, правам, владельцу, времени изменения и другим метаданным.

**Когда использовать:**
- Найти файлы с избыточными правами (аудит безопасности).
- Найти все файлы, изменённые за последние сутки (расследование инцидента).
- Найти все SUID-файлы в системе (поиск векторов эскалации).

**Пример:**
> find / -type f -perm 0777

**Особенность:** рекурсивно обходит диск, поэтому может быть медленным на больших файловых системах. Зато всегда выдаёт актуальный результат.

**Подробнее:** [[find]]

---

### 📄 2. `grep` — поиск текста внутри файлов

**Что ищет:** строки, содержащие заданный текст или регулярное выражение, внутри одного или нескольких файлов.

**Когда использовать:**
- Найти все строки с «error» в логе.
- Извлечь IP-адреса из файла с логами.
- Проверить, не прописан ли опасный параметр в конфигурации.

**Пример:**
> grep "Failed password" /var/log/auth.log

**Особенность:** не ищет имена файлов, только их содержимое. Часто используется в связке с `find` или в конвейере после `cat`, `journalctl`.

**Подробнее:** [[grep]], grep -oP (извлечение данных)

---

### ⚡ 3. `locate` — быстрый поиск имён файлов по базе данных

**Что ищет:** файлы и папки по имени, используя готовую базу данных (`mlocate.db`). Работает почти мгновенно.

**Когда использовать:**
- Быстро найти, где лежит конфигурационный файл (`locate sshd_config`).
- Проверить, есть ли в системе файлы с определённым расширением.

**Пример:**
> locate sudo

**Особенность:** не обходит диск, а читает базу данных, которая обновляется раз в сутки (`updatedb`). Свежесозданные файлы не видны до следующего обновления.

**Подробнее:** [[locate]]

---

### 🗺️ 4. `which` и `whereis` — поиск исполняемых программ

**Что ищет:** `which` показывает, **какой именно** исполняемый файл будет запущен по имени (путь в `$PATH`). `whereis` дополнительно ищет исходные коды и man-страницы.

**Когда использовать:**
- Узнать, откуда запускается `python` или `java`.
- Проверить, не подменил ли злоумышленник системную утилиту своей версией.

**Пример:**
> which ls

Выведет `/usr/bin/ls`.

**Особенность:** не ищет файлы по содержимому или атрибутам — только исполняемые программы в директориях, перечисленных в переменной `PATH`.

## 🆚 Сводная таблица

| Команда | Что ищет | Где ищет | Скорость | Актуальность |
|---|---|---|---|---|
| `find` | Файлы и папки по метаданным | Обходит диск | Медленная | Всегда актуально |
| `grep` | Текст внутри файлов | В указанных файлах или потоке | Средняя | Всегда актуально |
| `locate` | Имена файлов и папок | В базе данных `mlocate.db` | Мгновенно | Зависит от `updatedb` |
| `which` | Путь к исполняемой программе | В `$PATH` | Мгновенно | Всегда актуально |

## 🔗 Связи

- [[find]] — полный справочник по флагам.

- [[which]], [[whereis]] — поиск программ.
