# 🔢 wc — подсчёт строк, слов и символов

> [!abstract] Суть одной фразой
> `wc` (Word Count) — это команда для быстрого подсчёта количества строк, слов или байтов в файле либо в потоке данных. Для специалиста по ИБ это незаменимый инструмент при анализе логов: «сколько всего попыток входа?», «сколько уникальных IP-адресов атаковало?», «какой размер лога?».

---

## 📌 Базовое использование

**Подсчитать всё сразу (строки, слова, байты):**
> wc access.log

Выведет: `   120   480  3456 access.log`
(120 строк, 480 слов, 3456 байт).

**Взять данные из конвейера:**
> ps aux --no-headers | wc -l

Покажет количество процессов (потому что каждая строка — один процесс).

---

## 🔑 Ключевые опции

- `-l` (**l**ines) — показать только количество строк.
- `-w` (**w**ords) — показать только количество слов.
- `-c` (**c**ount bytes) — показать количество байт.
-  `-m` (**m**ulti-byte characters) — показать количество символов.
- `-L` (**L**ongest line) — показать длину самой длинной строки.

> grep "Failed password" /var/log/auth.log | wc -l

Покажет, сколько всего было неудачных попыток входа.

> awk -F: '{print $1}' /etc/passwd | wc -w

Покажет, сколько пользователей в системе (если считать слова).

---

## 🕵️ Типичные сценарии для ИБ

**Сколько IP атаковало сервер:**
> grep -oP 'from \K[0-9.]+' /var/log/auth.log | sort -u | wc -l

**Сколько файлов в папке с уликами:**
> ls -1 /evidence/ | wc -l

**Быстрая проверка, не растёт ли подозрительный лог:**
> wc -c /tmp/unknown.log

---

## 🔗 Связи

- [[cat]] — вывод содержимого файла, который можно передать в `wc`.
- [[grep]] — фильтрация строк перед подсчётом.
- [[sort]], [[uniq]] — подготовка данных для точного подсчёта уникальных значений.
- [[ps]] — подсчёт процессов (как в примере из практики).
- [[ls]] — подсчёт файлов в папке.

---

## 🧠 Значимость для меня как специалиста по ИБ

- Я знаю, что `wc -l` — самый быстрый способ ответить на вопрос «сколько?» при анализе логов.
- Я комбинирую `wc` с `grep` и `awk` для моментальной оценки масштаба инцидента.
- Я могу использовать `wc -c` для отслеживания аномального роста файлов (например, логов ошибок).

## 💬 Ответ на собеседовании (кратко)

> «`wc` — утилита для подсчёта строк, слов и байтов. Чаще всего я использую `wc -l` для подсчёта строк в выводе команд: количество процессов, число атакующих IP, размер логов. Это быстрый способ оценить масштаб проблемы без сложных инструментов».

## ❓ Самопроверка

1. **Как посчитать количество строк в файле?**
   👉 `wc -l файл`
2. **Как посчитать, сколько процессов запущено в системе?**
   👉 `ps aux --no-headers | wc -l`
3. **Что делает `wc -c`?**
   👉 Считает количество байт (размер файла или потока).
