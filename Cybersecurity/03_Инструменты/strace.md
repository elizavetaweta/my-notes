# 🔬 strace — трассировка системных вызовов

> [!abstract] Суть одной фразой
> `strace` (System Trace) — это утилита, которая показывает все системные вызовы (syscalls), выполняемые процессом. Для специалиста по ИБ это «рентген» программы: ты видишь, какие файлы она открывает, какие сетевые соединения устанавливает, какие данные читает и пишет.

---

## 📌 Базовое использование

**Запустить программу под трассировкой:**
> strace ./подозрительный_файл

**Присоединиться к уже работающему процессу (по PID):**
> strace -p 12345

**Показать только сетевые вызовы:**
> strace -e trace=network -p 12345

**Показать только операции с файлами:**
> strace -e trace=file -p 12345

**Сохранить вывод в файл:**
> strace -o /tmp/trace.log -p 12345

**Показать временные метки для каждого вызова:**
> strace -tt -p 12345

---

## 🔑 Ключевые опции

- `-p PID` — присоединиться к запущенному процессу.
- `-o файл` — сохранить вывод в файл.
- `-e trace=тип` — фильтр по типу вызовов (`file`, `network`, `process`, `signal`).
- `-f` — трассировать дочерние процессы (fork).
- `-c` — вывести итоговую статистику по вызовам.
- `-tt` — выводить время с микросекундами.

---

## 🕵️ Для специалиста по ИБ

- Я анализирую подозрительный бинарник, не запуская его в изолированной среде: `strace -f ./malware` покажет, что он пытается сделать.
- Я проверяю, куда легитимный процесс пишет данные и с кем соединяется по сети: `strace -e trace=network,write -p PID`.
- Я выявляю скрытые файлы: если процесс открывает файл в `/tmp/.hidden`, я это увижу в выводе.
