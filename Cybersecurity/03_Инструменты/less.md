# 📖 less — постраничный просмотр файлов

> [!abstract] Суть одной фразой
> `less` — это пейджер для просмотра текстовых файлов в терминале. Он позволяет листать файл вперёд и назад, искать текст, переходить по строкам — и всё это без загрузки всего файла в память. Для специалиста по ИБ это основной инструмент чтения логов и конфигураций.

---

## 📌 Базовое использование

> less /var/log/syslog

Откроет файл для просмотра. Выход из просмотра — клавиша `q`.

> less /etc/ssh/sshd_config

Так же удобно читать конфигурационные файлы.

---

## ⌨️ Основные клавиши управления

| Клавиша | Действие |
|---|---|
| `q` | Выйти из просмотра |
| `стрелки вверх/вниз`, `PageUp/PageDown` | Листать построчно или постранично |
| `/` | Поиск текста вперёд (ввести слово → `Enter`) |
| `?` | Поиск текста назад |
| `n` | Перейти к следующему совпадению поиска |
| `N` | Перейти к предыдущему совпадению поиска |
| `g` | Перейти в начало файла |
| `G` | Перейти в конец файла |
| `F` | Следить за обновлениями файла (как `tail -f`) |

> [!note] Почему называется `less`
> Название — игра слов: «less is more» (меньше — это больше). Программа `more` была стандартным пейджером, но `less` превзошла её по возможностям (в `more` нельзя листать назад). Отсюда шутка: `less` делает больше, чем `more`.

## 🔗 Связи

- [[Linux]] — основная ОС.
- [[cat]] — вывести файл целиком.
- [[tail]] — посмотреть последние строки файла или следить за обновлениями.
- [[grep]] — искать текст внутри файла (можно комбинировать с `less`).

## 🧠 Значимость для меня как специалиста по ИБ

- Я использую `less` каждый день: для чтения логов (`/var/log/`), конфигураций (`/etc/`), вывода команд (`systemctl status`).
- Я знаю, что `less` не загружает весь файл в память — это важно при анализе логов размером в гигабайты.
- Я умею быстро находить нужные строки в логах: открыл файл, нажал `/`, ввёл «Failed», нашёл все подозрительные попытки входа.

## ❓ Самопроверка

1. **Как выйти из просмотра файла в `less`?**
   👉 Нажать `q`.
2. **Как найти слово «error» в открытом файле?**
   👉 Нажать `/`, ввести `error`, нажать `Enter`.
3. **Чем `less` отличается от `cat`?**
   👉 `cat` выводит весь файл сразу, `less` позволяет листать его постранично и искать внутри, не загружая весь файл в память.
