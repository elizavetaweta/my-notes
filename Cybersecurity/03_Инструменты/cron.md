# ⏰ cron — планировщик периодических задач

> [!abstract] Суть одной фразой
> `cron` — это демон-планировщик, который выполняет команды по расписанию. Для специалиста по ИБ это инструмент автоматизации резервного копирования, проверки целостности и ротации логов, а также место, где злоумышленники часто прячут свои задачи для сохранения доступа.

---

## 📌 Как устроен cron

- У каждого пользователя есть свой **crontab** — файл с заданиями.
- Системные задачи хранятся в `/etc/crontab` и папках `/etc/cron.*/`.

**Редактировать свой crontab:**
> crontab -e

**Посмотреть свои задания:**
> crontab -l


## 🧩 Структура cron-выражения (что значат цифры и `*`)

Каждая строка cron состоит из пяти полей времени + команда:

минута час день_месяца месяц день_недели команда

| Поле | Допустимые значения |
|---|---|
| Минуты | 0–59 |
| Часы | 0–23 |
| День месяца | 1–31 |
| Месяц | 1–12 или jan–dec |
| День недели | 0–7 (0 и 7 — воскресенье) или sun–sat |

**Специальные символы:**
- `*` — любое значение (каждый день, каждый час и т.д.).
- `*/N` — каждые N единиц (`*/5` — каждые 5 минут).
- `N` — конкретное значение.
- `N,M,K` — перечисление (в указанные минуты, часы и т.д.).
- `N-M` — диапазон от N до M.

**Примеры:**
> `0 2 * * *` — каждый день в 2:00 ночи.
> `*/5 * * * *` — каждые 5 минут.
> `30 8 1 * *` — 1-го числа каждого месяца в 8:30 утра.
---

## 🔑 Примеры записей

> 0 2 * * * /opt/backup.sh

Запустит `backup.sh` каждый день в 2:00 ночи.

>   `*/5  * * * * /usr/local/bin/check_integrity.sh`

Запускает проверку целостности каждые 5 минут.

>[!note] Важно
> Сама строка `0 2 * * * /opt/backup.sh` — это уже готовая запись, которая помещается внутрь crontab-файла. Просто открой редактор командой `crontab -e`, вставь эту строку, сохрани и закрой — cron сам подхватит задание и начнёт выполнять его по расписанию.

---

## 🕵️ Для специалиста по ИБ

- При аудите всегда проверяю crontab всех пользователей и системные cron-папки на предмет подозрительных заданий:
  > cat /etc/crontab
  > ls /etc/cron.*
  > for user in $(cut -f1 -d: /etc/passwd); do crontab -u $user -l; done

## ❓ Самопроверка

1. **Как запускать скрипт каждый час?**
   👉 `0 * * * * /путь/к/скрипту`
2. **Где хранятся системные cron-задачи?**
   👉 В `/etc/crontab` и папках `/etc/cron.hourly`, `/etc/cron.daily` и т.д.
3. **Как проверить задания конкретного пользователя?**
   👉 `crontab -u username -l`
