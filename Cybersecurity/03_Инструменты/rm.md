# 🗑️ rm — удаление файлов и папок

> [!abstract] Суть одной фразой
> `rm` (Remove) — команда для удаления файлов и каталогов. В Linux удаление необратимо: файл не попадает в корзину, а его метаданные сразу удаляются из [[Файловая система|файловой системы]].

Для специалиста по ИБ `rm` — это не просто команда очистки, а инструмент, требующий особой осторожности, и одновременно способ безопасного уничтожения данных перед списанием носителя.

---

## 📌 Базовое использование

> rm filename.txt

Удалит файл `filename.txt` **без возможности восстановления** (не из корзины, а окончательно).

> rm file1.txt file2.txt file3.txt

Можно удалить несколько файлов одной командой.

---

## 🔑 Ключевые опции

- `-r` (recursive) — рекурсивно удалить папку и всё её содержимое.
- `-f` (force) — не спрашивать подтверждения, игнорировать несуществующие файлы.
- `-i` (interactive) — спрашивать подтверждение перед каждым удалением (защита от ошибок).
- *cлово - удалить файлы с определенным словом
  >rm *new

> rm -rf папка/

Полностью удалит папку со всем содержимым, без вопросов.

> [!danger] Осторожно с `rm -rf`
> Никогда не выполняй `rm -rf` от имени `root` без полной уверенности. Опечатка в пути (например, пробел перед `/`) может уничтожить всю систему. Это одна из самых опасных команд в Linux.

> rm -ri папка/

То же самое, но перед каждым удалением будет запрос подтверждения — безопаснее.

---

## 🔐 Безопасное удаление (с перезаписью)

Обычный `rm` удаляет только запись о файле, а сами данные остаются на диске до перезаписи. Для гарантированного уничтожения используй утилиту `shred`:

> shred -z -u secret.txt

`-z` — перезаписать нулями в конце, `-u` — удалить файл после перезаписи. Многократная перезапись случайными данными делает восстановление практически невозможным.

## 🧠 Значимость для меня как специалиста по ИБ

- Я знаю, что простое удаление (`rm`) не уничтожает данные физически. Для конфиденциальной информации я использую `shred` или полное шифрование диска с последующим сбросом ключей.
- Я понимаю опасность `rm -rf` и никогда не запускаю эту команду вслепую, особенно на серверах.
- При очистке логов после расследования я сначала архивирую их, и только потом удаляю — это стандартная процедура сохранения улик.

## 💬 Ответ на собеседовании (кратко)

> «`rm` удаляет файлы без возможности восстановления. `rm -r` — рекурсивно для папок, `-f` — без подтверждений. Комбинация `rm -rf` — одна из самых опасных, требует полной уверенности в пути. Для безопасного удаления конфиденциальных данных я использую `shred` с перезаписью случайными данными».

## ❓ Самопроверка

1. **Что делает `rm -rf /путь/к/папке`?**
   👉 Рекурсивно удаляет папку со всем содержимым без запроса подтверждения.
2. **Почему просто `rm` недостаточно для безопасного уничтожения секретного файла?**
   👉 Потому что данные на диске остаются и могут быть восстановлены утилитами вроде TestDisk.
3. **Как удалить папку с запросом подтверждения для каждого файла?**
   👉 `rm -ri папка/`
