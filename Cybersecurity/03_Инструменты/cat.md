# 🐱 cat — вывод содержимого файлов

> [!abstract] Суть одной фразой
> `cat` (concatenate) — это команда для вывода содержимого одного или нескольких файлов на экран, их объединения и быстрого создания небольших текстовых файлов. Для специалиста по ИБ это самый быстрый способ «заглянуть» в файл, не открывая редактор.

---

## 📌 Базовое использование

> cat filename.txt

Выведет всё содержимое файла прямо в терминал.

> cat file1.txt file2.txt

Выведет содержимое обоих файлов подряд (конкатенация).

---

## 🔑 Основные флаги

- `-n` (**n**umber) — пронумеровать все строки (включая пустые).
- `-b` (**b**lank‑ignoring) — пронумеровать только непустые строки.
- `-s` (**s**queeze) — сжать повторяющиеся пустые строки в одну.
- `-A` (**A**ll) — показать все скрытые символы: концы строк (`$`), табуляции (`^I`), непечатные символы.
- `-E` (**E**nd) — показать символ `$` в конце каждой строки.
- `-T` (**T**ab) — показать табуляции как `^I`.
- `-v` (**v**erbose) — показать непечатные символы в явном виде (кроме табуляции и конца строки).

## 🔑 Основные сценарии

**Просмотреть конфигурационный файл:**
> cat /etc/ssh/sshd_config

**Объединить несколько файлов в один:**
> cat part1.txt part2.txt > full.txt

**Создать небольшой файл с текстом (завершить ввод — `Ctrl+D`):**
> cat > newfile.txt
> Первая строка
> Вторая строка
> Ctrl+D

**Показать номера строк (`-n`):**
> cat -n /etc/ssh/sshd_config

---

## ⚠️ Когда НЕ стоит использовать cat

`cat` выгружает **весь файл** в терминал. Для больших логов (например, `/var/log/syslog` на сервере) это засоряет вывод. В таких случаях лучше использовать [[less]] (постраничный просмотр) или [[tail]] (последние строки).

---

## 🔗 Связи

- [[less]] — постраничный просмотр больших файлов.
- [[tail]] — просмотр последних строк и отслеживание изменений.
- [[grep]] — поиск текста внутри файла.
- [[Linux]] — основная ОС.

---

## 🧠 Значимость для меня как специалиста по ИБ

- Я использую `cat` для быстрого чтения конфигураций (`/etc/`) и проверки содержимого скриптов.
- Я знаю, что `cat` не подходит для больших логов, и в этих случаях переключаюсь на `less` или `tail -f`.
- Я помню, что `cat > file` может случайно перезаписать существующий файл, поэтому использую его осторожно.

---

## 💬 Ответ на собеседовании (кратко)

> «`cat` — это базовая команда для вывода содержимого файлов и их объединения. Подходит для небольших конфигурационных файлов и быстрого создания текста. Для больших логов использую `less` или `tail`, потому что `cat` выгружает всё содержимое сразу».

## ❓ Самопроверка

1. **Как объединить два файла в один?**
   👉 `cat file1.txt file2.txt > combined.txt`
2. **Почему для логов лучше использовать `less`, а не `cat`?**
   👉 `cat` выгружает весь файл в терминал, `less` позволяет листать постранично и не загружает файл в память целиком.
3. **Как посмотреть файл с номерами строк?**
   👉 `cat -n filename.txt`
