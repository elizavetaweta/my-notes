# 💻 Bash (Bourne Again Shell) — командная оболочка Linux

> [!abstract] Суть одной фразой
> Bash — это командная оболочка (shell), основной интерфейс взаимодействия пользователя с операционной системой [[Linux]] через терминал. Именно Bash принимает, интерпретирует и выполняет все команды, которые ты изучаешь: от `ls` до сложных скриптов.

Для специалиста по ИБ Bash — не просто «чёрное окно», а главный рабочий инструмент: среда для аудита, автоматизации, анализа логов и реагирования на инциденты.

---

## 📌 Что такое Bash и чем он отличается от терминала

- **Терминал** — это программа-«окно», в котором отображается командная строка (например, `gnome-terminal`, `iTerm2`, консоль WSL).
- **Bash** — это программа-«мозг», которая работает внутри терминала, читает введённые команды и выполняет их.

Терминал — это рама, Bash — это двигатель.

> [!note] Почему Bash так называется
> **B**ourne **A**gain **SH**ell — «возрождённая оболочка Борна». Создана как свободная замена оригинальной оболочки `sh` (Bourne Shell) с добавлением удобных возможностей: история команд, автодополнение, скрипты.

---

## 🔑 Базовые возможности Bash, важные для специалиста по ИБ

### 1. Автодополнение (Tab)
Экономит время и предотвращает опечатки. Начал вводить команду или путь → нажал `Tab` → Bash дополнил или показал варианты.

### 2. История команд
Стрелки `↑` и `↓` листают предыдущие команды. `Ctrl + R` — поиск по истории (набрал часть команды → Bash находит последнее совпадение). Все команды хранятся в `~/.bash_history`.

> [!note] Для расследования
> `history` показывает список команд текущего пользователя. При анализе инцидента это позволяет быстро восстановить, что делал администратор (или злоумышленник).

### 3. Переменные окружения
Bash хранит настройки в переменных, например:
- `$PATH` — список папок, в которых Bash ищет исполняемые файлы.
- `$HOME` — домашняя папка пользователя.
- `$USER` — имя текущего пользователя.

Просмотреть все переменные: `env`. Обратиться к переменной: `echo $HOME`.

### 4. Автоматизация (скрипты)
Bash умеет выполнять целые сценарии — файлы с расширением `.sh`, содержащие последовательность команд. Именно на Bash пишутся скрипты резервного копирования, проверки целостности, разбора логов и реагирования на инциденты.

### 5. Пайпы и перенаправление
- `|` (pipe) — передаёт вывод одной команды на вход другой.  
  `ps aux | grep sshd` — найти процесс `sshd` среди всех.
- `>` — перенаправляет вывод в файл (с перезаписью).  
  `cat /etc/passwd > users.txt`
- `>>` — дописывает вывод в конец файла.  
  `echo "alert" >> /var/log/audit.log`
- `<` — подаёт файл на вход команде.

Подробный разбор перенаправлений — в заметке [[Перенаправление ввода-вывода в Bash]].

## 🛠️ Программирование в Bash для автоматизации

Bash — это не только интерактивная среда, но и полноценный язык программирования. Ты можешь использовать **переменные**, **условия**, **циклы** и **функции** для написания скриптов, которые выполняют рутинную работу специалиста по ИБ.

### 📦 1. Переменные

Переменные хранят значения, чтобы использовать их позже в скрипте.

```bash
#!/bin/bash
# Объявление переменной (без пробелов вокруг '=')
target_user="root"
log_file="/var/log/auth.log"

# Использование переменной (со знаком $)
echo "Проверяем попытки входа для $target_user в файле $log_file"
```
>[!note] Правила
>Имена переменных чувствительны к регистру (User и user — разные).
>По соглашению имена переменных пишут в нижнем регистре, а имена констант (если они есть) — в верхнем.

### ⚖️ 2. Условные операторы (if)
Позволяют выполнять разные действия в зависимости от ситуации.

```bash
#!/bin/bash
critical_file="/etc/shadow"
if [ -f "$critical_file" ]; then
    echo "Файл $critical_file существует. Проверяем права..."
    if [ -r "$critical_file" ] && [ "$(stat -c %U "$critical_file")" != "root" ]; then
        echo "ТРЕВОГА: $critical_file читается не только root!"
    fi
else
    echo "Критичный файл $critical_file отсутствует!"
fi
```

Основные операторы сравнения:
- -f — это файл?
- -d — это директория?
- -r / -w / -x — читается / записывается / исполняется?
- == и != — сравнение строк.
- -eq, -ne, -lt, -gt — сравнение чисел.

### 🔁 3. Циклы (for, while)
Позволяют повторять однотипные действия над списком объектов или пока выполняется условие.

Перебор списка пользователей и проверка их домашних папок:

```bash
#!/bin/bash
for username in $(cut -f1 -d: /etc/passwd); do
    home_dir=$(eval echo ~$username)
    if [ -d "$home_dir" ] && [ -w "$home_dir" ]; then
        echo "Пользователь $username имеет доступ на запись в $home_dir"
    fi
done
```

### 🧩 4. Функции
Функции позволяют сгруппировать повторяющийся код и вызывать его по имени.

```bash
#!/bin/bash

# Объявление функции
block_ip() {
    local bad_ip=$1
    echo "Блокирую IP-адрес $bad_ip..."
    iptables -A INPUT -s "$bad_ip" -j DROP
    echo "$(date): $bad_ip заблокирован после множества неудачных попыток" >> /var/log/security.log
}

# Использование функции
# Сначала можно получить список атакующих IP
attacking_ips=$(grep "Failed password" /var/log/auth.log | awk '{print $(NF-3)}' | sort -u)
for ip in $attacking_ips; do
    # Тут могла бы быть проверка количества попыток
    block_ip "$ip"
done
```

>[!note] Ключевое слово local
Переменные внутри функции следует объявлять как local, иначе они станут глобальными и могут затереть значения извне.

1. **Чем Bash отличается от терминала?**  
    👉 Терминал — это окно, Bash — это программа, которая внутри этого окна выполняет команды.
    
2. **Как найти предыдущую команду, введённую час назад?**  
    👉 Нажать `Ctrl + R` и начать вводить фрагмент команды.

    👉 Чтобы избежать дублирования кода и структурировать логику (например, функцию `block_ip` можно вызывать много раз для разных адресов).
