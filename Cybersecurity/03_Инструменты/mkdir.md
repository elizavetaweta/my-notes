# 📁 mkdir — создание каталогов

> [!abstract] Суть одной фразой
> `mkdir` (Make Directory) — это команда для создания новых папок (каталогов) в [[Linux]]. Для специалиста по ИБ это инструмент быстрой организации изолированных сред, создания структуры для хранения улик и настройки защищённых директорий с ограниченным доступом.

---

## 📌 Базовое использование

**Создать одну папку:**

> mkdir новая_папка

**Создать несколько папок одновременно:**

> mkdir папка1 папка2 папка3

**Создать вложенную структуру папок одной командой:**

> mkdir -p проект/логи/аудит/2025

Если родительские папки (`проект`, `логи`, `аудит`) не существуют, флаг `-p` создаст их автоматически. Без `-p` команда выдаст ошибку.

---

## 🔑 Ключевые опции

- `-p` (parents) — создать родительские папки, если их нет. Не выдаёт ошибку, если папка уже существует.
- `-m режим` (mode) — установить права доступа при создании (аналог `chmod` сразу).

> mkdir -m 700 /секретная_папка

Создаст папку, в которую сможет заходить только владелец.

> mkdir -p /var/log/archive/2025/05/

Создаст всю цепочку папок за одну команду.

---

## ⚠️ Типичные ошибки

- **Без `-p` при создании вложенной структуры:**
  `mkdir a/b/c` выдаст ошибку, если `a` или `a/b` не существуют. Всегда используй `-p` для вложенных папок.

- **Пробелы в именах:**
  `mkdir Мои Документы` создаст **две** папки: `Мои` и `Документы`. Чтобы создать одну папку с пробелом, нужно взять имя в кавычки: `mkdir "Мои Документы"`.

---

## 🕵️ Сценарии для специалиста по ИБ

### 1. Создание изолированной среды для анализа

> mkdir -p /quarantine/malware/{samples,reports,logs}

Создаст структуру для хранения образцов вредоносного ПО, отчётов и логов.

### 2. Настройка защищённой папки для улик

> mkdir -m 700 /evidence && chattr +a /evidence

Создаст папку, доступную только владельцу, и установит атрибут «только добавление» (нельзя удалить файлы).

### 3. Быстрое воссоздание структуры конфигураций

> mkdir -p /etc/backup/{nginx,ssh,cron}

Создаст папки для резервных копий конфигураций трёх сервисов.

---

## 💡 Фигурное расширение `{...}` — быстрый способ создать несколько папок

Bash позволяет одной командой создать сразу несколько папок или файлов через фигурные скобки.

> mkdir -p /путь/{папка1,папка2,папка3}

Bash «размножит» путь и создаст три папки. Скобки работают и с файлами:

> touch /путь/{file1,file2,file3}.txt

А для диапазонов можно использовать `..`:

> mkdir проект_{1..5}

Создаст папки: `проект_1`, `проект_2`, ..., `проект_5`.

## 🔗 Связи

- [[rmdir]] — удаление пустых папок.
- [[rm]] — удаление непустых папок (`rm -r`).
- [[chmod]] — изменение прав на уже созданную папку.
- [[ls]] — проверка, что папки создались.
- [[Linux]] — основная ОС.

## ❓ Самопроверка

1. **Как создать папку `reports` внутри `audit`, если `audit` ещё не существует?**
   👉 `mkdir -p audit/reports`
2. **Как создать папку, доступную только владельцу?**
   👉 `mkdir -m 700 папка`
3. **Почему `mkdir a/b/c` без `-p` может не сработать?**
   👉 Потому что родительские папки `a` и `a/b` могут не существовать, и команда выдаст ошибку.
