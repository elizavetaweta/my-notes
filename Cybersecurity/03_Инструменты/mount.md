# 💿 mount — монтирование файловых систем

> [!abstract] Суть одной фразой
> `mount` подключает файловую систему (диск, раздел, ISO-образ, сетевой ресурс) к дереву каталогов [[Linux]]. Для специалиста по ИБ это инструмент доступа к уликам на внешних носителях, а также проверки: не подмонтировал ли злоумышленник скрытый раздел.

---

## 🧠 Что значит «монтировать» (простая аналогия)

Монтировать устройство — это процесс подключения флешки, диска или другого накопителя к файловой системе компьютера, при котором его файлы становятся доступны для чтения и записи.

Представь, что файловая система Linux — это стеллаж с книгами. Все папки (`/home`, `/var`, `/etc`) — это его полки.

- **Устройство (флешка, диск, образ)** — это коробка с новыми книгами, которую ты принесла.
- **Монтирование** — это процесс, при котором ты ставишь эту коробку на одну из полок стеллажа (в конкретную папку, например `/mnt/usb`).
- **Содержимое устройства становится доступно через эту папку.**

Пока ты не смонтируешь устройство, система видит только саму «коробку» (файл устройства `/dev/sdb1`), но не знает, как добраться до «книг» внутри неё.

После монтирования ты заходишь в папку и работаешь с файлами устройства как с обычными.


## 📌 Базовое использование

**Посмотреть все примонтированные устройства:**
> mount

**Подмонтировать флешку (раздел `/dev/sdb1`) в папку `/mnt/usb`:**
> sudo mount /dev/sdb1 /mnt/usb

**Отмонтировать:**
> sudo umount /mnt/usb

**Монтировать ISO-образ:**
> sudo mount -o loop image.iso /mnt/iso

**Монтировать только для чтения (важно для улик):**
> sudo mount -o ro /dev/sdb1 /mnt/evidence

---

## 🔑 Файл `/etc/fstab`

Содержит список автоматически монтируемых при загрузке разделов. При аудите я проверяю, нет ли в нём подозрительных записей:
> cat /etc/fstab

---

## 🕵️ Для специалиста по ИБ

- При подключении носителя с уликами всегда монтирую **только для чтения** (`-o ro`), чтобы не изменить метаданные.
- Проверяю скрытые точки монтирования, которые злоумышленник мог использовать для маскировки данных:
  > mount | grep -vE "(proc|sys|dev|tmpfs|cgroup)"

## 🧠 Значимость для меня

- Я знаю, что работа с уликами начинается с монтирования в режиме `ro`, чтобы гарантировать целостность данных.
- Я проверяю `/etc/fstab` и вывод `mount` на предмет скрытых или необычных разделов — это может быть след работы злоумышленника.

## 💬 Ответ на собеседовании (кратко)

> «`mount` подключает файловые системы к дереву каталогов. Я монтирую внешние носители с уликами в режиме `ro`, чтобы сохранить целостность. `mount` без аргументов показывает все активные точки монтирования — проверяю их при аудите».

## ❓ Самопроверка

1. **Как смонтировать флешку только для чтения?**
   👉 `sudo mount -o ro /dev/sdb1 /mnt/usb`
2. **Как посмотреть все смонтированные устройства?**
   👉 `mount`
3. **Где хранятся правила автоматического монтирования?**
   👉 В файле `/etc/fstab`.
