# ⚙️ ifcfg, ifup, ifdown — управление интерфейсами через конфигурационные файлы

> [!abstract] Суть
> `ifcfg`, `ifup` и `ifdown` — это не просто команды, а часть системы управления сетевыми интерфейсами, характерной для дистрибутивов на основе Red Hat (RHEL, CentOS, Fedora). В современных системах они часто заменены NetworkManager, но до сих пор встречаются на серверах.

- **`ifcfg`** — префикс конфигурационных файлов в `/etc/sysconfig/network-scripts/` (например, `ifcfg-eth0`).
- **`ifup`** — скрипт для поднятия интерфейса по его конфигурационному файлу.
- **`ifdown`** — скрипт для остановки интерфейса по его конфигурационному файлу.

Для специалиста по ИБ это важно: конфигурационные файлы могут быть целью атаки для перенаправления трафика или отключения защиты.

- `ifcfg` — **i**nter**f**ace **c**on**f**i**g** (конфигурация интерфейса). Префикс конфигурационных файлов в `/etc/sysconfig/network-scripts/`, например `ifcfg-eth0`.
- `ifup` — **i**nter**f**ace **up** (поднять интерфейс). Скрипт, который читает конфигурационный файл и активирует сетевой интерфейс.
- `ifdown` — **i**nter**f**ace **down** (опустить интерфейс). Скрипт, который останавливает сетевой интерфейс по его конфигурационному файлу.

---

## 📌 Базовое использование

**Поднять интерфейс:**
> ifup eth0

**Остановить интерфейс:**
> ifdown eth0

---

## 📄 Пример конфигурационного файла (`/etc/sysconfig/network-scripts/ifcfg-eth0`)
DEVICE=eth0
BOOTPROTO=static
ONBOOT=yes
IPADDR=192.168.1.100
NETMASK=255.255.255.0
GATEWAY=192.168.1.1
DNS1=8.8.8.8

- `ONBOOT=yes` — интерфейс будет поднят при загрузке.
- `BOOTPROTO=dhcp` — получение IP по DHCP (вместо статики).

---

## 🕵️ Значимость для специалиста по ИБ

- Я знаю, что злоумышленник, получив root-доступ, может изменить конфигурационный файл и добавить подложный шлюз или DNS-сервер для перехвата трафика.
- При аудите я проверяю директорию `/etc/sysconfig/network-scripts/` на наличие незнакомых файлов `ifcfg-*`, особенно созданных не администратором.
- Я понимаю, что `ifdown` может быть использован для отключения критичного интерфейса (DoS).

## ❓ Самопроверка

1. **Где хранятся конфигурационные файлы `ifcfg-*`?**
   👉 В `/etc/sysconfig/network-scripts/` (на Red Hat-подобных системах).
2. **Что делает `ifdown eth0`?**
   👉 Останавливает сетевой интерфейс `eth0`.
3. **Почему права на файлы `ifcfg-*` должны быть ограничены?**
   👉 Потому что их изменение может привести к перехвату трафика (подмена шлюза, DNS) или отказу в обслуживании.
