# ✂️ cut — извлечение столбцов из текста

> [!abstract] Суть одной фразой
> `cut` — это команда для вырезания определённых полей (столбцов) или символов из каждой строки файла или потока. Для специалиста по ИБ это незаменимый инструмент при анализе логов: извлечь IP-адреса, имена пользователей, временные метки.

---

## 📌 Базовое использование

**Вырезать по разделителю (поля):**

> cut -d ':' -f 1 /etc/passwd

- `-d ':'` — разделитель (двоеточие).
- `-f 1` — вывести первое поле.

Выведет список всех пользователей системы.
Как это работает:
Утилита берет файл /etc/passwd (там хранятся учетные записи системы). 
Строки в нем выглядят так: root:x:0:0:root:/root:/bin/bash.-d ':' (delimiter): 
Говорит команде: «Считай каждое двоеточие границей между колонками».-f 1 (field): Говорит: «Возьми только первую колонку (поле) из получившихся».
Результат: Из строки root:x:0:0... вырезается и выводится только слово root. 
Так как операция повторяется для каждой строки, на выходе вы получаете чистый список всех пользователей.

**Вырезать по позициям символов:**

> cut -c 1-10 filename.txt

Выведет первые 10 символов каждой строки.

---

## 🔑 Ключевые опции

- `-d 'символ'` (**d**elimiter) — задать разделитель полей. По умолчанию разделителем является табуляция.
- `-f N` (**f**ield) — вывести поле с номером N 
  Номер поля в `cut` — это просто порядковый номер столбца в строке, считая слева направо. Нумерация начинается с **1** (не с нуля!). Первый столбец — это поле номер 1, второй — поле номер 2 и так далее.
- `-f N,M` — вывести поля N и M (через запятую).
- `-f N-M` — вывести поля от N до M включительно.
- `-c N-M` (**c**haracter) — вывести символы с позиции N по M (нумерация с 1).
- `--complement` — вывести всё, **кроме** указанных полей. Инверсия выбора.

> cut -d ':' -f 1,3 /etc/passwd

Выведет имя пользователя и его UID.

> cut -d ' ' -f 1 access.log

Выведет первый столбец (обычно IP-адрес) из лога веб-сервера.

## 🕵️ Сценарии для ИБ

**Извлечь IP-адреса из лога:**

> grep "Failed password" /var/log/auth.log | cut -d ' ' -f 11
> 

>[!note] Важно
>В выводе команды между столбцами может быть разное количество пробелов, поэтому такой подход ненадёжен. Лучше использовать `awk`, который сам схлопывает повторяющиеся пробелы и не требует указывать разделитель явно.
>grep "Failed password" /var/log/auth.log | awk '{print $11}'
>Обе команды пытаются взять 11-й столбец, но `awk` делает это надёжнее.

**Извлечь имена пользователей из `/etc/passwd` для аудита:**

> cut -d ':' -f 1 /etc/passwd | sort
