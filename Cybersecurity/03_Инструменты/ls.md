# 📋 ls — список файлов и папок

> [!abstract] Суть одной фразой
> `ls` (List) — это команда для просмотра содержимого каталогов. С флагами `-la` она показывает подробную информацию о каждом файле: права доступа, владельца, размер и дату изменения. Для специалиста по ИБ это первый инструмент аудита прав и поиска подозрительных файлов.

---

## 📌 Базовое использование

> ls

Покажет файлы и папки в текущей директории (без скрытых).

> ls /etc/ssh/

Покажет содержимое папки `/etc/ssh/`.

> ls -la

**Полный вывод** со всей информацией (подробности — ниже).

---

## 🔍 Как читать вывод `ls -la`

Пример строки:

> -rw-r----- 1 root shadow 1234 Mar 15 10:30 /etc/shadow

Разберём каждый столбец:

| Столбец | Пример | Что означает |
|---|---|---|
| **Тип и права** | `-rw-r-----` | Тип файла + права доступа (см. ниже) |
| **Ссылки** | `1` | Количество жёстких ссылок на файл |
| **Владелец** | `root` | Владелец файла |
| **Группа** | `shadow` | Группа-владелец файла |
| **Размер** | `1234` | Размер в байтах |
| **Дата и время** | `Mar 15 10:30` | Время последней модификации |
| **Имя** | `/etc/shadow` | Имя файла или каталога |

---

## 🔐 Тип файла и права доступа

Первый столбец состоит из 10 символов. Разберём на том же примере `-rw-r-----`:

| Позиция | Символ | Значение |
|---|---|---|
| 1 | `-` | **Тип файла:** `-` = обычный файл, `d` = каталог, `l` = символическая ссылка |
| 2–4 | `rw-` | Права **владельца**: чтение (r), запись (w), выполнение (-) |
| 5–7 | `r--` | Права **группы**: чтение (r), запись (-), выполнение (-) |
| 8–10 | `---` | Права **остальных**: ничего нельзя |

**Другие типы файлов:**

| Символ | Тип файла             | Название (англ.)  | Суть                                                    |
| ------ | --------------------- | ----------------- | ------------------------------------------------------- |
| `-`    | Обычный файл          | Regular file      | Текст, бинарник, скрипт, лог, ключ                      |
| `d`    | Каталог               | Directory         | Папка, содержащая имена других файлов                   |
| `l`    | Символическая ссылка  | Symbolic link     | Указатель на другой файл или папку                      |
| `b`    | Блочное устройство    | Block device      | Доступ к данным блоками (жёсткий диск, SSD)             |
| `c`    | Символьное устройство | Character device  | Поточный доступ к данным (терминал, клавиатура, мышь)   |
| `s`    | Сокет                 | Socket            | Межпроцессное взаимодействие (IPC), в т.ч. по сети      |
| `p`    | Именованный канал     | Named pipe (FIFO) | Передача данных между процессами через файловую систему |

> [!note] Запомнить
> `d` в начале строки — это папка, `l` — ссылка на другой файл. Всё остальное, что начинается с `-`, — обычный файл (ключ, лог, скрипт).

---

## 🔑 Полезные опции

- `-l` — длинный формат (long): права, владелец, размер, дата.
- `-a` — показать все файлы, включая скрытые (начинающиеся с точки).
- `-h` — «человеческий» размер (Human-readable): `1.2K` вместо `1234`.
- `-t` — сортировать по времени изменения (сначала свежие).
- `-r` — обратный порядок сортировки.
- `-R` — рекурсивно показать содержимое всех вложенных папок.

> ls -lah /var/log

Покажет всё содержимое `/var/log` с правами, размерами в килобайтах/мегабайтах и скрытыми файлами.

---

## 🕵️ Аудит прав доступа

Для специалиста по ИБ `ls -la` — основной способ проверить, не выставлены ли избыточные права.

> ls -la /etc/shadow

Должен показывать `-rw-r-----` или `-rw-------`. Если права `-rw-r--r--` — любой пользователь может прочитать хеши паролей. Это критическая уязвимость.

> ls -la ~/.ssh/

Ключи SSH должны иметь права `600` (`-rw-------`). Если видно `-rw-r--r--`, ключ могут скопировать другие пользователи.

> ls -la /tmp

Временная папка, доступная всем на запись — популярное место для скриптов злоумышленников. При аудите я всегда проверяю её содержимое.

## ❓ Самопроверка

1. **Что показывает первый символ в строке `ls -la`?**
   👉 Тип файла: `d` — папка, `l` — ссылка, `-` — обычный файл.
2. **Как посмотреть все файлы, включая скрытые, с читаемыми размерами?**
   👉 `ls -lah`
3. **Какие права считаются опасными для `/etc/shadow`?**
   👉 Любые, кроме `-rw-r-----` или `-rw-------`. Если видно `r--` для «остальных», это критическая проблема.
