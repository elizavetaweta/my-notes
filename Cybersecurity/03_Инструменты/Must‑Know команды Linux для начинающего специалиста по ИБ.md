# 🎯 Must‑Know: команды Linux для начинающего специалиста по ИБ

> [!abstract] Назначение
> Это «швейцарский нож» специалиста — минимальный набор команд, который нужен с первого дня работы. Без них невозможно провести аудит, прочитать логи или диагностировать атаку. Все перечисленные команды уже описаны в отдельных атомарных заметках.

## 📂 Навигация и просмотр
- **`ls -la`** — список файлов с правами, владельцами и скрытыми объектами. Твой «глаз» в системе. → [[ls]]
- **`cd`** — перемещение по каталогам. → [[cd]]

## 📄 Чтение и поиск
- **`cat`** — вывод конфигурационных файлов. → [[cat]]
- **`less`** — безопасный просмотр больших логов. → [[less]]
- **`grep`** — поиск текста (ошибок, IP, подозрительных строк). → [[grep]]
- **`tail -f`** — мониторинг логов в реальном времени. → [[tail]]

## 🔐 Права доступа
- **`chmod`** — изменение прав (`600` для ключей, `644` для конфигов). → [[chmod]]
- **`chown`** — смена владельца и группы. → [[chown]]

## 📊 Процессы и система
- **`ps aux`** — статический снимок всех процессов. → [[ps]]
- **`top`** — интерактивный монитор нагрузки. → [[top]]
- **`kill`** — завершение процесса. → [[kill]]
- **`df -h`** — контроль свободного места на дисках. → [[df и du]]
- **`free -h`** — контроль оперативной памяти и swap. → [[free]]

## 🌐 Сеть
- **`ip a`** — просмотр IP-адресов и состояния интерфейсов. → [[ip addr]]
- **`ss -tuln`** — аудит открытых портов. → [[ss]]
- **`ping`** — проверка доступности хоста.

## 👥 Пользователи
- **`whoami` / `id`** — проверка текущей учётной записи и её групп. → [[whoami и id]]
- **`sudo`** — выполнение привилегированных команд с логированием. → [[sudo]]

---

> [!note] Как этим пользоваться
> Это не список для заучивания. Открой каждую заметку по ссылке и попробуй выполнить команду в терминале. Потом возвращайся к этому списку, чтобы освежить память перед собеседованием.
