# 🖨️ printf — форматированный вывод текста

> [!abstract] Суть одной фразой
> `printf` (print formatted) — это команда для вывода текста по заданному шаблону. В отличие от [[echo]], которая просто печатает строку, `printf` даёт полный контроль над тем, как именно будут выглядеть данные: можно задавать переносы строк, выравнивание, количество знаков после запятой и тип данных.

Для специалиста по ИБ `printf` — это инструмент создания «чистых», структурированных отчётов, логов и конфигурационных файлов, где пробелы, отступы и переносы строк критически важны.

---

## 📌 Базовое использование

> printf "шаблон" аргумент1 аргумент2 ...

Строка формата (`шаблон`) содержит обычный текст и **спецификаторы формата**, которые начинаются с `%`. `printf` проходит по строке и заменяет каждый `%...` очередным аргументом.

**Пример из лабораторной работы:**

```bash 
printf '%s %s\n' "$(uname -r)" "$(uname -m)" > system_info.txt
```
>[!note]  Почему тут два %s?
Потому что у нас два аргумента: $(uname -r) и $(uname -m) и мы хотим поместить их на одной строке.
Каждый %s — это «окошечко», в которое printf вставляет один аргумент. Первый %s заполняется первым аргументом (версия ядра), второй %s — вторым (архитектура). А пробел между %s и %s — это просто пробел в выводе, чтобы слова не склеивались. 
Если бы мы передали три аргумента, нам понадобилось бы три %s. Если один — один %s. Количество %s должно совпадать с количеством аргументов. 
А когда мы хотим передать три аргумента с новой строки, то нужен только один %s\n. Когда шаблон только один, а аргументов несколько, printf **повторно применяет** этот шаблон к каждому следующему аргументу.


```bash
printf "%s\n" "$(uname -r) $(uname -m)""$(uptime -p)" "$(hostname)" > system_info.txt
```

## 🔍 Разбор команды по частям

**1. `"%s\n"` — шаблон (строка формата).**
   - `%s` — спецификатор **s**tring. Означает: «возьми следующий аргумент и вставь его сюда как обычный текст».
   - `\n` — символ перевода строки (newline). После каждого аргумента будет новая строка.

**2. `"$(uname -r) $(uname -m)"` — первый аргумент.**
   Это **одна строка**, результат подстановки двух команд. Например, `6.18.32-1-MANJARO x86_64`. Она будет вставлена на место первого `%s`.

**3. `"$(uptime -p)"` — второй аргумент.**
   Результат команды `uptime -p`, например `up 3 hours, 29 minutes`. Вставляется на место второго `%s`.

**4. `"$(hostname)"` — третий аргумент.**
   Имя хоста, например `nightsong`. Вставляется на место третьего `%s`.

**5. `> system_info.txt` — перенаправление вывода в файл.**


## 🧩 Что значит `%s` и как аргументы подставляются в шаблон

`%s` — это **спецификатор строки** (**s**tring). Он работает как пустое поле в бланке, которое нужно заполнить следующим по порядку аргументом.

**Простой пример:**

> printf "Пользователь %s зашёл с IP %s\n" "alice" "10.0.0.1"

Первый `%s` заполняется `alice`, второй — `10.0.0.1`. Результат: `Пользователь alice зашёл с IP 10.0.0.1`.

Если аргументов больше, чем `%s` в шаблоне, `printf` применяет шаблон повторно к каждому оставшемуся аргументу. Именно это позволяет выводить список строк одной короткой командой:

> printf "%s\n" "строка1" "строка2" "строка3"

Эквивалентно трём отдельным `echo`, но с полным контролем над форматом.

---

## 🔑 Ключевые спецификаторы формата

- `%s` — вставить аргумент как строку (**s**tring).
- `%d` — вставить аргумент как целое число (**d**ecimal).
- `%f` — вставить аргумент как число с плавающей точкой (**f**loat).
- `\n` — символ перевода строки (newline).
- `\t` — символ табуляции (tab).

**Пример со смешанными типами:**

> printf "Пользователь: %s, UID: %d\n" "$(whoami)" "$(id -u)"

Выведет: `Пользователь: shadowbunny, UID: 1000`

## 🆚 `printf` vs `echo`

| Характеристика | `printf` | `echo` |
|---|---|---|
| **Перенос строки** | Только если явно указан `\n` | Добавляет автоматически |
| **Форматирование** | Полный контроль через `%...` | Нет, только вывод строки как есть |
| **Поведение** | Предсказуемое во всех оболочках | Может отличаться (`-e`, `-n`) |
| **Когда использовать** | Скрипты, отчёты, точный вывод | Быстрый вывод одной строки |

> [!note] Правило выбора
> Если нужно просто вывести сообщение — используй `echo`. Если важен точный формат (переносы, отступы, числа) — используй `printf`.

## 🕵️ Примеры для специалиста по ИБ

**Формирование заголовка отчёта с разделителями:**

> printf "=== Отчёт о системе %s ===\nДата: %s\nЯдро: %s\n" "$(hostname)" "$(date)" "$(uname -r)"

**Создание CSV-строки для журнала инцидентов:**

> printf "%s,%s,%s\n" "$(date +%Y-%m-%dT%H:%M:%S)" "Failed login" "192.168.1.100"

## ❓ Самопроверка

1. **Как вывести три слова на отдельных строках?**
   👉 `printf "%s\n" слово1 слово2 слово3`
2. **Чем `printf` принципиально отличается от `echo`?**
   👉 `printf` не добавляет перенос строки автоматически и требует явного указания формата (`%s`, `\n`). `echo` выводит строку как есть и сама ставит перевод строки.
3. **Как вывести строку с именем пользователя и его UID?**
   👉 `printf "User: %s, UID: %d\n" "$(whoami)" "$(id -u)"`
