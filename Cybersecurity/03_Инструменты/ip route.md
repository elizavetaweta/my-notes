# 🧭 ip route — управление таблицей маршрутизации

> [!abstract] Суть одной фразой
> `ip route` — это объект команды [[ip]] для просмотра, добавления и удаления маршрутов в таблице маршрутизации. Для специалиста по ИБ это основной инструмент проверки, куда система отправляет пакеты, и обнаружения подозрительных маршрутов, которые могут перенаправлять трафик злоумышленнику.

---

## 📌 Базовое использование

**Посмотреть таблицу маршрутизации:**
> ip route show
> ip r

**Добавить маршрут до конкретной сети:**
> ip route add 10.0.0.0/24 via 192.168.1.1

**Добавить маршрут по умолчанию (шлюз):**
> ip route add default via 192.168.1.1

**Удалить маршрут:**
> ip route del 10.0.0.0/24

---

## 🔍 Как читать вывод

> default via 192.168.1.1 dev eth0
> 192.168.1.0/24 dev eth0 proto kernel scope link src 192.168.1.100

- `default` — маршрут по умолчанию (шлюз).
- `via` — следующий узел, через который идёт трафик.
- `dev eth0` — интерфейс, через который отправляются пакеты.
- `proto kernel` — маршрут добавлен ядром автоматически при настройке IP.

---

## 🕵️ Примеры для специалиста по ИБ

**Проверить шлюз по умолчанию:**
> ip route | grep default

Если шлюз изменился на неизвестный IP — это признак MITM-атаки или компрометации.

**Проверить, не появились ли маршруты к конкретным хостам (перехват трафика):**
> ip route | grep -v "^default"

**Добавить временный маршрут для изолированной сети (лабораторная):**
> ip route add 192.168.56.0/24 via 192.168.1.1

---

## 🔑 Управление несколькими таблицами маршрутизации (policy routing)

В Linux можно создавать несколько таблиц маршрутизации и направлять в них трафик по правилам.

**Посмотреть таблицу с номером 100:**
> ip route show table 100

**Добавить маршрут в таблицу 100:**
> ip route add 10.0.0.0/24 via 192.168.1.1 table 100

Policy routing используется для разделения трафика (VPN, гостевые сети) — важно для ИБ.
