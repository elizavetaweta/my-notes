# 🔢 uniq — поиск уникальных и повторяющихся строк

> [!abstract] Суть одной фразой
> `uniq` — это команда для поиска уникальных или повторяющихся строк в **отсортированном** файле или потоке. Для специалиста по ИБ это основной инструмент подсчёта частоты событий: количество попыток входа с одного IP, уникальные имена пользователей, повторяющиеся ошибки.

---

## 📌 Базовое использование

**Удалить дубликаты (оставить только уникальные строки):**

> sort file.txt | uniq

**Показать только дублирующиеся строки:**

> sort file.txt | uniq -d

**Подсчитать количество повторов каждой строки:**

> sort file.txt | uniq -c

---

## 🔑 Ключевые опции

- `-c` (**c**ount) — подсчитать количество повторов каждой строки и вывести число перед строкой.
- `-d` (**d**uplicate) — вывести только строки, которые встречаются **более одного раза** (дубликаты).
- `-u` (**u**nique) — вывести только строки, которые встречаются **ровно один раз**.
- `-i` (**i**gnore case) — игнорировать регистр букв при сравнении строк.

> sort ips.txt | uniq -c | sort -rn

Выведет IP-адреса, отсортированные по убыванию частоты появления.

---

## 🕵️ Сценарии для ИБ

**Топ-5 атакующих IP из лога:**

> grep "Failed password" /var/log/auth.log | cut -d ' ' -f 11 | sort | uniq -c | sort -rn | head -5

**Найти пользователей, которые встречаются в списке более одного раза:**

> sort users.txt | uniq -d

## ❓ Самопроверка

1. **Почему перед `uniq` нужно выполнять `sort`?**
   👉 `uniq` сравнивает только соседние строки, `sort` группирует одинаковые вместе.
2. **Как подсчитать, сколько раз каждая строка встречается в файле?**
   👉 `sort file.txt | uniq -c`
