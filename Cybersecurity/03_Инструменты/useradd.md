# 👤 useradd — создание нового пользователя

> [!abstract] Суть одной фразой
> `useradd` — это команда для создания новых учётных записей пользователей в [[Linux]]. Она добавляет запись в `/etc/passwd`, создаёт домашнюю папку и устанавливает оболочку по умолчанию.

Для специалиста по ИБ важно уметь создавать изолированные учётные записи для сервисов и проверять, не появились ли в системе нелегитимные пользователи после взлома.

---

## 📌 Базовое использование

> useradd -m -s /bin/bash alice

- `-m` — создать домашнюю папку (`/home/alice`).
- `-s /bin/bash` — указать командную оболочку.

После создания нужно задать пароль командой `passwd alice`.

---

## 🔑 Ключевые опции

- `-m` — создать домашнюю папку.
- `-s /путь/к/оболочке` — задать оболочку (например, `/bin/bash`, `/bin/nologin`).
- `-G группа1,группа2` — добавить в дополнительные группы.
- `-e YYYY-MM-DD` — установить дату истечения учётной записи.

> useradd -m -s /bin/nologin -e 2025-12-31 tempworker

Создаст учётную запись, которая не сможет войти в систему интерактивно, и истечёт в конце года.

## 🔗 Связи

## ❓ Самопроверка

1. **Как создать пользователя без возможности входа в систему?**
   👉 `useradd -m -s /bin/nologin username`
2. **Где хранится информация о созданных пользователях?**
   👉 В файле `/etc/passwd` и частично в `/etc/shadow` (пароли).
