# 📡 tcpdump — перехват и анализ сетевого трафика

> [!abstract] Суть одной фразой
> `tcpdump` — это консольный анализатор сетевых пакетов. Он позволяет в реальном времени видеть, какие данные передаются через сетевые интерфейсы. Для специалиста по ИБ это основной инструмент для обнаружения атак, анализа подозрительного трафика и расследования инцидентов.

---

## 📌 Базовое использование

**Показать весь трафик на интерфейсе (требует root):**
> sudo tcpdump -i eth0

**Показать только пакеты, относящиеся к хосту:**
> sudo tcpdump host 192.168.1.100

**Показать только трафик на порт 22 (SSH):**
> sudo tcpdump port 22

**Сохранить трафик в файл для последующего анализа (pcap):**
> sudo tcpdump -w /tmp/capture.pcap

**Читать трафик из файла:**
> sudo tcpdump -r /tmp/capture.pcap

---

## 🔑 Ключевые опции

- `-i интерфейс` — указать интерфейс (`eth0`, `any` — все).
- `-n` — не преобразовывать IP в имена (быстрее).
- `-nn` — не преобразовывать ни IP, ни порты.
- `-v`, `-vv`, `-vvv` — подробность вывода (verbose).
- `-c N` — остановиться после N пакетов.
- `-A` — показать содержимое пакета в ASCII (читаемый текст).
- `-X` — показать содержимое в hex и ASCII.

> sudo tcpdump -i eth0 -nn port 443 -c 10

Покажет 10 пакетов HTTPS без DNS-резолвинга.

---

## 🕵️ Для специалиста по ИБ

- Обнаруживаю подозрительные соединения: `tcpdump -i any -nn not port 22 and not port 443` — всё, что не SSH и не HTTPS.
- Перехватываю трафик для анализа вредоносной активности и сохраняю в pcap.
- Ищу передачу паролей или токенов в открытом виде (HTTP, FTP, Telnet): `tcpdump -A port 21 or port 23 or port 80`.

## ❓ Самопроверка

1. **Как перехватить 5 пакетов на порту 80 и сохранить в файл?**
   👉 `sudo tcpdump -i any -c 5 -w http.pcap port 80`
2. **Что делает флаг `-A`?**
   👉 Показывает содержимое пакета в текстовом виде.
3. **Как посмотреть трафик, ранее сохранённый в файл?**
   👉 `sudo tcpdump -r файл.pcap`
