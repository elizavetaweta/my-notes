# 📄 head — просмотр первых строк файла

> [!abstract] Суть одной фразой
> `head` — это команда для вывода первых строк текстового файла. По умолчанию показывает 10 строк. Для специалиста по ИБ это быстрый способ проверить заголовки логов, начало конфигураций или выходных данных любой команды.

---

## 📌 Базовое использование

> head filename.txt

Выведет **первые 10 строк** файла (значение по умолчанию).

> head -n 20 /etc/ssh/sshd_config

Выведет первые 20 строк.

---

## 🔑 Основные опции

- `-n N` — вывести `N` первых строк.
- `-c N` — вывести `N` первых **байт** (полезно для бинарных файлов, но для текстовых обычно используют `-n`).
- `-q` (quiet) — не выводить заголовки с именем файла (удобно при просмотре нескольких файлов).

> head -n 5 /var/log/syslog

Покажет первые 5 записей системного лога — часто достаточно, чтобы понять, когда был последний запуск или есть ли ошибки на старте.

---

## 🕵️ Примеры для специалиста по ИБ

> head -n 50 access.log | cut -d' ' -f1 | sort | uniq -c | sort -rn

Покажет топ IP-адресов, с которых чаще всего обращались к веб-серверу (первые 50 строк лога → извлечь первый столбец → посчитать повторы → отсортировать). Быстрый способ обнаружить подозрительную активность.

> head /etc/shadow

Покажет первых пользователей с паролями — полезно при аудите, чтобы понять, какие учётные записи имеют парольную защиту.

> ls -la /var/log/ | head -n 3

Покажет первые три файла в директории с логами — быстро увидеть, что логирует система.

## 🧠 Значимость для меня как специалиста по ИБ

- Я использую `head` для быстрого просмотра начала конфигурационных файлов и логов, чтобы понять их структуру.
- Я знаю, что `head` в связке с другими утилитами (`cut`, `sort`, `uniq`) позволяет быстро провести первичный анализ логов.
- Я помню, что `head` не подходит для мониторинга в реальном времени — для этого использую `tail -f`.

## ❓ Самопроверка

1. **Как посмотреть первые 15 строк файла?**
   👉 `head -n 15 filename.txt`
2. **Чем `head` отличается от `tail`?**
   👉 `head` показывает начало файла, `tail` — конец. `tail -f` умеет следить за обновлениями, `head` — нет.
3. **Как посмотреть первые строки вывода другой команды?**
   👉 `команда | head -n 10`
