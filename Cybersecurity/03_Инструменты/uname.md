# 🖥️ uname — информация о системе и ядре

> [!abstract] Суть одной фразой
> `uname` (Unix Name) выводит информацию о текущей операционной системе: название, версию ядра, архитектуру процессора. Для специалиста по ИБ это первый шаг при оценке уязвимостей: устаревшее ядро — цель для эксплуатации.

---

## 📌 Базовое использование

**Вся информация одним флагом:**
> uname -a

 `-a` → **a**ll (вся информация).

**Только версия ядра:**
> uname -r

`-r` → **r**elease (версия ядра).

**Только архитектура:**
> uname -m

`-m` → **m**achine (архитектура процессора)

---

## 🔑 Основные флаги

> [!note] Расшифровка флагов
> - `-a` → **a**ll (вся информация).
> - `-r` → **r**elease (версия ядра).
> - `-m` → **m**achine (архитектура процессора).
> - `-n` → **n**odename (имя хоста).
> - `-s` → **s**ystem (тип операционной системы, всегда `Linux`).
> - `-v` → **v**ersion (дата и время сборки ядра).
> - `-o` → **o**perating system (полное название ОС, например `GNU/Linux`).

| Флаг | Значение | Пример вывода |
|---|---|---|
| `-a` (**a**ll) | Вся информация сразу | `Linux nightsong 6.18.32-1-MANJARO #1 SMP PREEMPT_DYNAMIC Sun, 17 May 2026 ... x86_64 GNU/Linux` |
| `-r` (**r**elease) | Только версия ядра | `6.18.32-1-MANJARO` |
| `-m` (**m**achine) | Архитектура процессора | `x86_64` |
| `-n` (**n**odename) | Имя хоста | `nightsong` |
| `-s` (**s**ystem) | Тип ОС | `Linux` |
| `-v` (**v**ersion) | Дата сборки ядра | `#1 SMP PREEMPT_DYNAMIC Sun, 17 May 2026 20:29:55 +0000` |
| `-o` (**o**perating system) | Полное название ОС | `GNU/Linux` |

**Примеры:**

> uname -a
> uname -r
> uname -m
> uname -n

## 🔑 Пример вывода

> Linux myserver 5.15.0-91-generic #101-Ubuntu SMP Tue Nov 14 13:30:00 UTC 2023 x86_64 x86_64 x86_64 GNU/Linux

- `Linux` — тип ОС.
- `5.15.0-91-generic` — версия ядра.
- `x86_64` — архитектура процессора.

---

## 🕵️ Примеры для специалиста по ИБ

**Проверить версию ядра (устаревшее = уязвимое):**
> uname -r

**Проверить архитектуру (для подбора эксплойтов):**
> uname -m

**Полная информация для инвентаризации системы:**
> uname -a > system_info.txt

## 🧠 Значимость для меня как специалиста по ИБ

- Я знаю, что `uname -r` — первая команда для оценки patch-level системы. Устаревшее ядро может содержать известные уязвимости.
- Я проверяю архитектуру, чтобы точно подобрать версию устанавливаемого ПО или модуля ядра (например, для защиты).
