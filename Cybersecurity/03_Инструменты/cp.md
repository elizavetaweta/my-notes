# 📋 cp — копирование файлов и папок

> [!abstract] Суть одной фразой
> `cp` (Copy) — команда для копирования файлов и каталогов. В отличие от перемещения (`mv`), исходный файл остаётся на месте. Для специалиста по ИБ `cp` — это инструмент для создания резервных копий перед изменениями, дублирования конфигураций и сохранения улик при расследовании.

---

## 📌 Базовое использование

**Копировать файл (Copy) в указанное место:**
> cp filename.txt /путь/назначения/

Если нужно скопировать и сразу переименовать файл, укажите новое имя в конце:
>cp file.txt /home/user/documents/new_file.txt

**Сделать бэкап файла в той же самой папке:**
>cp filename.txt. filename_copy.txt

Копировать папку со всем содержимым:
>cp -r /var/www/site /home/user/backup/

---

## 🔑 Ключевые опции

- `-r` (recursive) — рекурсивно скопировать папку со всем содержимым.
- `-p` (preserve) — сохранить метаданные: владельца, права доступа, временные метки.
- `-i` (interactive) — спрашивать подтверждение, если файл с таким именем уже существует (защита от перезаписи).
- `-u` (update) — копировать только если исходный файл новее, чем целевой, или целевой отсутствует.

> cp -r /etc/nginx/ /backup/nginx_configs/

Создаст полную копию папки конфигураций Nginx.

> cp -p file.txt /backup/

Скопирует файл, сохранив его владельца и права — важно при создании резервных копий критичных файлов (ключей, конфигов).

## ⚠️ Копирование папки-источника vs копирование её содержимого

> cp -r /etc/pam.d MyRoot/Dir1

Если целевая папка `Dir1` существует, `cp` поместит `pam.d` **внутрь** неё. Результат: `MyRoot/Dir1/pam.d/...`

> cp -r /etc/pam.d/* MyRoot/Dir1/

Копирует **содержимое** `pam.d` прямо в `Dir1`. Результат: `MyRoot/Dir1/common-auth` и так далее.

> [!note] Правило для запоминания
> `cp -r папка существующая_папка` — копирует саму папку со всем содержимым внутрь целевой.
> `cp -r папка/* существующая_папка/` — копирует только содержимое папки, без неё самой.

---

## 🕵️ Типовые сценарии для специалиста по ИБ

**Резервное копирование конфигураций перед правкой:**
> cp /etc/ssh/sshd_config /etc/ssh/sshd_config.bak

Всегда делай копию перед изменением — это спасёт от блокировки доступа к серверу.

**Сохранение логов при расследовании:**
> cp -p /var/log/auth.log /evidence/auth_$(date +%Y%m%d).log

Флаг `-p` сохранит оригинальные временные метки — это критично для судебной значимости улик.

**Копирование с удалённого сервера (`scp`):**
> scp user@server:/etc/shadow /local/backup/

`scp` — это `cp` через SSH. Используется для безопасного копирования между машинами.

## 🔗 Связи

- [[Файловая система]] — `cp` создаёт новую запись в файловой системе.
- [[rm]] — удаление, обратная операция.
- [[mv]] — перемещение, аналог `cp` + `rm` исходника.
- [[chmod]] — права доступа на скопированный файл могут измениться, если не использовать `-p`.

## 🧠 Значимость для меня как специалиста по ИБ

- Я всегда делаю резервную копию конфигурационных файлов перед их изменением (`cp config config.bak`). Это стандартная процедура, позволяющая быстро откатить изменения.
- При расследовании инцидента я копирую логи и временные файлы с сохранением оригинальных метаданных (`cp -p`), чтобы не нарушить целостность улик.
- Я знаю, что `cp` без флага `-p` может изменить владельца и права на файл, и учитываю это при работе с чувствительными данными.

## ❓ Самопроверка

1. **Как скопировать папку со всем содержимым?**
   👉 `cp -r папка/ /путь/назначения/`
2. **Как скопировать файл, сохранив его владельца и права?**
   👉 `cp -p файл /путь/назначения/`
3. **Чем `cp` отличается от `mv`?**
   👉 `cp` оставляет исходный файл на месте, `mv` перемещает (удаляет исходник).
