# 🔍 grep — поиск текста в файлах и выводе команд

> [!abstract] Суть одной фразой
> `grep` (Global Regular Expression Print) — это команда для поиска строк, содержащих заданный текст или шаблон, в одном или нескольких файлах. Для специалиста по ИБ это основной инструмент анализа логов и конфигураций.

---

## 📌 Базовое использование

> grep "что_ищем" файл.txt

Например, найти все строки с ошибками в логе:

> grep "ERROR" /var/log/syslog

Искать в нескольких файлах сразу:

> grep "password" *.txt

---

## 🔑 Ключевые опции

- `-i` (**i**gnore case) — игнорировать регистр (находить и «Password», и «password»).
- `-r` (**r**ecursive) — рекурсивный поиск по всем файлам в папке.
- `-n` (line **n**umber) — показывать номер строки, где найдено совпадение.
- `-c` (**c**ount) — вывести только количество найденных строк.
- `-v` (in**v**ert match) — инвертировать поиск (показать строки, которые **не** содержат шаблон).
- `--color` — подсветить найденное в выводе (часто включено по умолчанию).

# 🎯 grep -oP: как извлечь конкретный фрагмент из строки

> [!abstract] Суть одной фразой
> Комбинация `grep -oP` позволяет не просто найти строку по шаблону, а **вырезать и показать только ту часть строки**, которая тебе нужна. Это незаменимо при анализе логов, когда нужно быстро извлечь IP-адреса, имена пользователей или коды ошибок из «стены текста».

В отличие от [[cut]], который требует жёсткой структуры с разделителями, `grep -oP` работает с самим содержимым строки.

---

## 📌 Разбор ключевых опций

- `-o` (**o**nly matching) — показать не всю строку, а **только ту часть, которая совпала с шаблоном**.
- `-P` (**P**erl) — использовать Perl-совместимые регулярные выражения (PCRE). Это самый мощный диалект, в котором работают продвинутые трюки.

## 🧠 Что даёт флаг `-P` (Perl-совместимые регулярки)

Обычный `grep` использует базовый диалект регулярных выражений (BRE). Флаг `-P` переключает его на Perl-совместимый диалект (PCRE), который добавляет продвинутые возможности:

- `\K` — «забудь всё, что совпало до меня». Позволяет найти строку по контексту, но показать только нужную часть.
- `(?<=...)` и `(?=...)` — lookbehind и lookahead. Позволяют проверить, что перед или после искомого фрагмента стоит определённый текст, не включая его в результат.
- `\d`, `\w`, `\s` — сокращения для `[0-9]`, `[a-zA-Z0-9_]` и пробельных символов.

Без `-P` эти конструкции недоступны, и для извлечения данных пришлось бы комбинировать несколько команд.

---

## 🧩 Магия `\K`: «забудь всё, что было до»

В Perl-регулярках есть специальная конструкция `\K`, которая означает: **«всё, что совпало до меня — отбросить, а показать только то, что совпадёт после»**.

Это как сказать `grep`: «Найди в строке слово `from`, но не показывай его. А покажи только IP-адрес, который идёт сразу после».

**Синтаксис:**
> grep -oP 'префикс\K[шаблон_того_что_нужно_извлечь]+' файл

 знак + означает «одно или более совпадений». Если его не поставить, команда найдёт только первый символ IP-адреса вместо всего адреса целиком.

## 🕵️ Пример из лабораторной работы

**Задача:** из файла `failed_attempts.log` извлечь только IP-адреса атакующих.

Строка выглядит так:
> May 20 08:15:23 nightsong sshd[1234]: Failed password for root from 185.220.101.34 port 45678 ssh2

IP-адрес всегда идёт после слова `from `.

**Команда:**
> grep -oP 'from \K[0-9.]+' failed_attempts.log

**Что здесь происходит:**

1.  `grep -oP` — ищем с использованием Perl-регулярок и показываем только совпадение.
2.  `'from \K[0-9.]+'` — шаблон:
    -   `from ` — найти текст «from » (с пробелом).
    -   `\K` — **забыть** «from ». Оно нужно для поиска, но в результат не попадёт.
    -   `[0-9.]+` — захватить последовательность из цифр и точек (то есть IP-адрес).
3.  `failed_attempts.log` — файл, в котором ищем.

**Результат:** список IP-адресов, по одному на строку, готовый для передачи в `sort | uniq -c | sort -rn`.

## 🕵️ Примеры для специалиста по ИБ

> grep "Failed password" /var/log/auth.log

Покажет все неудачные попытки входа по SSH (брутфорс-атаки).

> grep -r "PermitRootLogin" /etc/ssh/

Найдёт, где в конфигурациях SSH задан параметр прямого доступа для root.

> grep -v "^#" /etc/nginx/nginx.conf

Выведет все активные строки конфигурации, исключая закомментированные (начинающиеся с `#`).

> ps aux | grep sshd

Отфильтрует вывод `ps aux` и покажет только процесс SSH-сервера. Классический приём: `grep` часто используют в связке с другими командами через конвейер (`|`).
