# 📢 echo — вывод текста в терминал и создание файлов

> [!abstract] Суть одной фразой
> `echo` — это команда для вывода строки текста на экран или в файл. Кажется простой, но для специалиста по ИБ это основной инструмент быстрого создания конфигурационных заметок, добавления строк в логи и проверки переменных окружения в скриптах.

---
echo оправдан, когда нужно объединить вывод нескольких команд в одну строку или добавить свой текст.

Здесь echo не нужен:
hostname >> system_info.txt

Здесь echo необходим:
echo $(uname -r) $(uname -m) > system_info.txt
Без `echo` я бы просто не смогла записать версию ядра и архитектуру процессрова вместе через пробел одной командой.

Также можно было через printf:

```bash 
printf '%s %s\n' "$(uname -r)" "$(uname -m)" > system_info.txt
```
>[!note]  Почему тут два %s?
Потому что у нас два аргумента: $(uname -r) и $(uname -m) и мы хотим поместить их на одной строке.
Каждый %s — это «окошечко», в которое printf вставляет один аргумент. Первый %s заполняется первым аргументом (версия ядра), второй %s — вторым (архитектура). А пробел между %s и %s — это просто пробел в выводе, чтобы слова не склеивались. 
Если бы мы передали три аргумента, нам понадобилось бы три %s. Если один — один %s. Количество %s должно совпадать с количеством аргументов.  А когда мы хотим передать три аргумента с новой строки, то нужен только один %s\n. Когда шаблон только один, а аргументов несколько, printf **повторно применяет** этот шаблон к каждому следующему аргументу.

## 📌 Базовое использование

**Вывести текст на экран:**

> echo "Hello, World!"

**Вывести содержимое переменной окружения:**

> echo $HOME
> echo $USER

**Вывести результат команды (через подстановку):**

> echo "Сегодня: $(date)"

---

## 🔑 Ключевые опции

- `-n` — **отменяет автоматический вывод символа новой строки** в самом конце сообщения (вывод останется на той же строке).
> echo -n "Введите пароль: "

Курсор останется на той же строке после двоеточия — удобно для приглашений в скриптах.

- `-e` — включить интерпретацию escape-последовательностей (`\n`, `\t`, `\\`).
Буква `-e` в названии флага происходит от английского слова escape (экранирование) или enable interpretation (включить интерпретацию).
По умолчанию echo выводит спецсимволы вроде \n или \t как обычный текст. Флаг -e заставляет командную строку обрабатывать их как команды форматирования.
Популярные спецсимволы для -e:
- \n — перенос на новую строку.
- \t — горизонтальная табуляция (отступ).
- \b — стирание предыдущего символа (Backspace).
-  \ \  — вывод самого символа обратного слэша.

> echo -e "Первая строка\nВторая строка"

Выведет текст в две строки. Без `-e` вывело бы `\n` как обычные символы.

## 📄 Создание и наполнение файлов

**Создать файл с текстом (перезапишет, если файл существует):**

> echo "System audit started" > audit.log

**Добавить строку в конец файла (безопасно):**

> echo "$(date): проверка завершена" >> audit.log

**Создать сразу несколько строк (с `-e`):**

> echo -e "user: $(whoami)\ndate: $(date)\nhost: $(hostname)" > system_info.txt

## 🕵️ Сценарии для специалиста по ИБ

### 1. Быстрое прототипирование конфигураций

> echo "export TMOUT=600" >> /etc/profile.d/security.sh

Добавляет строку автоматического выхода из системы при бездействии (защита от забытых сессий).

### 2. Маркировка событий при ручном аудите

> echo "$(date): проверка прав на /etc/shadow завершена" >> audit_timeline.log

Позволяет восстановить хронологию действий при расследовании.

### 3. Проверка переменных в скриптах

> echo "DEBUG: PATH=$PATH"

Помогает отлаживать скрипты, когда нужно понять, почему команда не находится.

### 4. Создание временных файлов с содержимым

> echo "192.168.1.100" > /tmp/blocked_ip.txt

Быстрая заготовка для последующей обработки.

## 🧩 Подстановка команд: `$(...)`

`echo` часто используют вместе с **подстановкой команд** (command substitution). Конструкция `$(...)` выполняет команду внутри скобок и вставляет её вывод прямо в строку.

> echo "Версия ядра: $(uname -r), архитектура: $(uname -m)"

Bash сначала выполняет `uname -r` и `uname -m`, а затем передаёт их результаты в `echo`. Это позволяет создавать динамические строки без ручного копирования.

**Аналогия:** `$(...)` работает как умный калькулятор: ты вводишь формулу, а он подставляет готовый ответ.

## 🧠 Значимость для меня как специалиста по ИБ

- Я знаю, что `echo` — это самый быстрый способ создать заметку, временный конфиг или пометить событие в логе без вызова редактора.
- Я всегда использую `>>` вместо `>`, если файл уже существует и я хочу дополнить его, а не перезаписать.
- Я понимаю разницу между `echo` и `cat > file`: `echo` удобен для одной строки, `cat > file` — для нескольких строк, вводимых вручную.

## ❓ Самопроверка

1. **Как создать файл с текстом «done»?**
   👉 `echo "done" > file.txt`
2. **Как добавить строку в конец файла, не удаляя старое содержимое?**
   👉 `echo "new line" >> file.txt`
3. **Что делает `echo -n`?**
   👉 Выводит текст без символа перевода строки в конце.
