# 📖 man — встроенная справка по командам

> [!abstract] Суть одной фразой
> `man` (Manual) — это команда для просмотра встроенной документации по любой команде, конфигурационному файлу или системному вызову [[Linux]]. Это первый источник, куда нужно заглянуть, если непонятна опция или синтаксис.

Умение пользоваться `man` — признак самостоятельного специалиста. Никто не помнит все опции, но каждый умеет быстро найти их в документации.

---

## 📌 Базовое использование

> man ls

Откроет страницу руководства по команде `ls`. Выход из просмотра — клавиша `q`.

> man grep

Покажет все опции `grep` с подробными пояснениями.

---

## 🔑 Разделы (sections) руководства

Команда `man` группирует документацию по разделам. Иногда нужно указать раздел явно, чтобы получить нужную страницу.

| Номер | Раздел | Пример |
|---|---|---|
| 1 | Пользовательские команды | `man 1 ls` |
| 5 | Форматы конфигурационных файлов | `man 5 sshd_config` |
| 7 | Общие темы, соглашения | `man 7 signal` |
| 8 | Команды администрирования (root) | `man 8 iptables` |

> man 5 sshd_config

Откроет справку по структуре конфигурационного файла SSH-сервера, а не по команде `sshd`.

---

## ⌨️ Управление при просмотре

Клавиши те же, что и в [[less]] (потому что `man` использует `less` для отображения):

| Клавиша | Действие |
|---|---|
| `q` | Выйти |
| `стрелки`, `PageUp/PageDown` | Листать |
| `/` | Поиск текста вперёд |
| `n` / `N` | Следующее / предыдущее совпадение |

---

## 🔑 Поиск нужной страницы

> man -k ключевое_слово

Покажет список всех страниц, в описании которых встречается это слово.

> man -k password

Выведет все команды и файлы, связанные с паролями (`passwd`, `chpasswd`, `shadow` и т.д.).

---

## 🔗 Связи

- [[Linux]] — основная ОС.
- [[less]] — пейджер, используемый `man` для отображения.
- Все остальные команды в шпаргалке имеют свои `man`-страницы.

## ❓ Самопроверка

1. **Как открыть справку по конфигурационному файлу `sshd_config`, а не по команде `sshd`?**
   👉 `man 5 sshd_config`
2. **Как найти все страницы, связанные с паролями?**
   👉 `man -k password`
3. **Как выйти из просмотра `man`?**
   👉 Нажать `q`.
