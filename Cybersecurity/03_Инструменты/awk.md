# 🔬 awk — мощная обработка текста по столбцам и условиям

> [!abstract] Суть одной фразой
> `awk` — это не просто команда, а полноценный язык для построчной обработки текста. Если `cut` умеет только вырезать столбец, а `grep` — только фильтровать строки, то `awk` делает и то, и другое одновременно, плюс может считать, форматировать вывод и выполнять арифметические операции.

Для специалиста по ИБ `awk` — это «швейцарский нож» анализа логов: извлечь IP-адреса, посчитать байты, найти строки по условию, переформатировать вывод.

Название `awk` образовано от первых букв фамилий её создателей: **A**lfred **A**ho, **P**eter **W**einberger и **B**rian **K**ernighan. Это такой же «именной» инструмент, как `sed` (Stream Editor) или `grep` (Global Regular Expression Print).

---

## 📌 Базовое использование

**Вывести конкретный столбец (поля разделены пробелами или табуляцией):**

> awk '{print $1}' access.log

Выведет первый столбец (обычно IP-адрес).

**Вывести несколько столбцов с разделителем:**

> awk '{print $1, $3}' access.log

**Использовать другой разделитель (например, двоеточие для `/etc/passwd`):**

> awk -F ':' '{print $1, $3}' /etc/passwd

Выведет имя пользователя и его UID.

---

## 🔑 Ключевые флаги

- `-F 'символ'` (**F**ield separator) — задать разделитель полей. По умолчанию `awk` разделяет строки по пробелам и табуляции. Этот флаг незаменим при анализе файлов с другим разделителем, например `/etc/passwd` (двоеточие).
- `-v имя=значение` (**v**ariable) — передать внешнюю переменную в скрипт `awk`. Позволяет использовать значения из shell (например, порог предупреждений) внутри `awk`, не усложняя синтаксис.
- `-f файл` (**f**ile) — прочитать скрипт `awk` из файла, а не писать его прямо в командной строке. Удобно для сложных и повторно используемых сценариев.
- `-W` — управление расширенными опциями (например, совместимостью или обработкой пробелов). Используется редко, но может пригодиться в старых скриптах.

> [!tip] Примеры для ИБ
> Разобрать лог с нестандартным разделителем:
> ```bash
> awk -F '|' '{print $3}' custom.log
> ```
> Передать пороговое значение для поиска аномалий:
> ```bash
> awk -v threshold=10 '$1 > threshold {print $0}' access.log
> ```

## 🔑 Ключевые возможности

**Фильтрация строк по условию:**

>awk '/IT/' information.txt

Выведет строки, содержащие конкретное значение  в файле.


>awk '/IT/{print $1, $2}' information.txt

Если мы хотим увидеть только несколько столбцов из строки, которая содержит IT.

> awk '/Failed password/ {print $11}' /var/log/auth.log

Выведет IP-адрес (11-й столбец) только из строк, содержащих «Failed password».


> awk '$3 > 1000' /etc/passwd

Выведет только строки, где третий столбец (UID) больше 1000 (обычные пользователи).


>awk '/^O/' information.txt

Выведет строку, начинающуюся с заданной буквы. 
Эта команда выбирает все строки с текстом, начинающимся на O.
Действие команды начинается с символа ^, который указывает на начало строки. После этого прописывается буква, с которой нужная вам строка должна начинаться.

По аналогичному принципу можно выводить строку, завершающуюся конкретным шаблоном:

>awk '/0$/' information.txt

Эта команда выводит строки, оканчивающиеся на 0 – здесь с помощью символа $ мы указываем, как должна заканчиваться нужная строка.

При этом её можно несколько изменить:

>awk '! /0$/' information.txt 

Символ `!` используется в качестве приставки «НЕ», а значит, в этом случае будут выбраны строки, которые не оканчиваются на `0`.


**Счётчики и агрегация:**

> awk '{sum += $1} END {print sum}' numbers.txt

Просуммирует числа из первого столбца и выведет результат.

**Форматирование вывода:**

> awk -F ':' '{printf "User: %-15s UID: %s\n", $1, $3}' /etc/passwd

Выведет красиво отформатированную таблицу.

## 🧠 Переменные и счётчики в awk (простая аналогия)

`awk` может работать как робот с блокнотами-счётчиками. Ты создаёшь переменную, обнуляешь её в блоке `BEGIN`, а затем в основном блоке (без метки) увеличиваешь её при обработке каждой строки.

**Пример: подсчёт общего количества процессов и процессов root за один проход:**

```bash
ps aux --no-headers | awk '
BEGIN { total = 0; root = 0 }
{
    total++
    if ($1 == "root") root++
}
END {
    printf "Total processes: %d\nRoot processes: %d\n", total, root
}'
```


## 🕵️ Сценарии для специалиста по ИБ

**Извлечь IP-адреса и посчитать количество попыток (аналог `grep | cut | sort | uniq -c | sort -rn`):**

> awk '/Failed password/ {count[$11]++} END {for (ip in count) print count[ip], ip}' /var/log/auth.log | sort -rn

**Проверить, есть ли пользователи с UID 0 (кроме root):**

> awk -F ':' '$3 == 0 {print $1}' /etc/passwd

**Посчитать общий размер файлов в папке:**

> ls -la | awk '{sum += $5} END {print "Total:", sum, "bytes"}'

## awk
> [!question]- Как вывести первый и третий столбцы из вывода `ps aux`?
> `ps aux | awk '{print $1, $3}'`


> [!question]- Как найти всех пользователей с UID ≥ 1000 в `/etc/passwd`?
> `awk -F ':' '$3 >= 1000 {print $1}' /etc/passwd`


> [!question]- Чем `awk` удобнее `cut` при работе с логами?
> `awk` автоматически схлопывает повторяющиеся пробелы в один разделитель, поэтому номера столбцов не «плывут». `cut` считает каждый пробел отдельным полем, что делает его ненадёжным для разбора логов с плавающим форматированием.
