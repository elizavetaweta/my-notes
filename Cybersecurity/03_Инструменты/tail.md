# 📄 tail — просмотр последних строк файла и отслеживание изменений

> [!abstract] Суть одной фразой
> `tail` — это команда для вывода последних строк текстового файла. В режиме `-f` она «следит» за файлом и показывает новые строки в реальном времени. Для специалиста по ИБ это основной инструмент мониторинга логов.

---

## 📌 Базовое использование

> tail /var/log/syslog

Выведет **последние 10 строк** файла (значение по умолчанию).

> tail -n 50 /var/log/auth.log

Выведет последние 50 строк.

> tail -f /var/log/auth.log

Будет следить за файлом и показывать новые строки по мере их появления. Выход — `Ctrl+C`.

---

## 🔑 Основные опции

- `-n N` — вывести `N` последних строк.
- `-f` (follow) — следить за обновлениями файла в реальном времени.
- `-F` — то же, что `-f`, но переживает ротацию логов (если файл был переименован, `tail` продолжит следить за новым файлом с тем же именем).
- `-q` (quiet) — не выводить заголовки с именем файла (удобно при просмотре нескольких файлов).

---

## 🕵️ Примеры для специалиста по ИБ

> tail -f /var/log/auth.log

Позволяет в реальном времени видеть все попытки входа, в том числе подбор паролей.

> tail -n 100 /var/log/syslog | grep -i error

Покажет последние 100 строк системного лога и отфильтрует только сообщения об ошибках (связка с [[grep]]).

> tail -F /var/log/nginx/access.log

Следит за логом веб-сервера, даже если файл был переименован во время ротации — важно при долгосрочном мониторинге.

## 🧠 Значимость для меня как специалиста по ИБ

- Я использую `tail -f` при расследовании инцидентов, чтобы видеть атаки в реальном времени.
- Я знаю, что `-F` надёжнее, чем `-f`, потому что переживает ротацию логов — это важно при длительном мониторинге на продакшн-серверах.
- Я комбинирую `tail` с `grep` для быстрого поиска ошибок в конце большого лога.

## ❓ Самопроверка

1. **Как посмотреть последние 20 строк лога?**
   👉 `tail -n 20 /var/log/syslog`
2. **Чем `-f` отличается от `-F`?**
   👉 `-f` следит за файлом, но теряет его при ротации. `-F` продолжит следить за новым файлом с тем же именем.
3. **Как посмотреть последние строки и сразу отфильтровать ошибки?**
   👉 `tail -n 100 /var/log/syslog | grep -i error`
