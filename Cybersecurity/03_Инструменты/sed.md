# ✏️ sed — потоковый редактор для замены, удаления и трансформации текста

> [!abstract] Суть одной фразой
> `sed` (Stream Editor) — это команда для автоматической замены, удаления, вставки и трансформации текста в потоке или файле. Если `grep` находит строки, а `awk` обрабатывает столбцы, то `sed` **редактирует** текст по правилам без открытия редактора.

Для специалиста по ИБ `sed` незаменим при массовой правке конфигураций, обезличивании логов и подготовке данных для отчётов.

---

## 📌 Базовое использование

**Заменить первое вхождение в каждой строке:**

> sed 's/старое/новое/' file.txt

**Заменить все вхождения в каждой строке (флаг `g`):**

> sed 's/старое/новое/g' file.txt

**Удалить строки, соответствующие шаблону:**

> sed '/шаблон/d' file.txt

**Вывести только строки с номера N по M:**

> sed -n '5,10p' file.txt

---

## 🔑 Ключевые опции

- `-i` — редактировать файл **на месте** (будь осторожна!).
- `-i.bak` — редактировать на месте, но сохранить резервную копию с расширением `.bak`.
- `-n` — не выводить строки по умолчанию (только то, что запрошено через `p`).
- `s/что/на_что/` — замена (substitute).
- `d` — удалить строку (delete).
- `p` — вывести строку (print).

> sed -i.bak 's/PasswordAuthentication yes/PasswordAuthentication no/' /etc/ssh/sshd_config

Заменит параметр в конфигурации SSH, сохранив резервную копию.

> sed -i '/^#/d' /etc/ssh/sshd_config

Удалит все закомментированные строки из конфигурации.

---

## 🕵️ Сценарии для специалиста по ИБ

**Обезличить IP-адреса в логах перед передачей отчёта:**

> sed 's/[0-9]\+\.[0-9]\+\.[0-9]\+\.[0-9]\+/x.x.x.x/g' access.log > sanitized.log

**Заменить истекающий пароль во всех файлах в папке (рекурсивно, с осторожностью):**

> find . -type f -exec sed -i 's/old_password/new_password/g' {} \;

**Раскомментировать строку в конфигурации (удалить `#` в начале):**

> sed -i 's/^#PermitRootLogin/PermitRootLogin/' /etc/ssh/sshd_config

## 🔗 Связи

- [[grep]] — найти строки перед заменой.
- [[awk]] — обработка столбцов (иногда комбинируется с `sed`).
- [[vim]] / [[nano]] — интерактивные редакторы, `sed` — автоматический.
- [[Перенаправление ввода-вывода в Bash]] — `sed` часто используется в конвейере.

## ❓ Самопроверка

1. **Как заменить все пробелы на подчёркивания в файле?**
   👉 `sed 's/ /_/g' file.txt`
2. **Как удалить строки, содержащие слово «error», из файла?**
   👉 `sed '/error/d' file.txt`
3. **Почему `sed -i` может быть опасен?**
   👉 Он изменяет файл без подтверждения. Ошибка в шаблоне может испортить конфигурацию, если нет резервной копии.
