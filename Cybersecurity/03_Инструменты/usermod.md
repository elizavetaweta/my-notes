# 🔄 usermod — изменение учётной записи пользователя

> [!abstract] Суть одной фразой
> `usermod` (User Modify) — команда для изменения параметров существующей учётной записи: имени, домашней папки, оболочки, групп и срока действия.

---

## 📌 Базовое использование

> usermod -aG docker alice

Добавит пользователя `alice` в группу `docker`. Флаг `-a` (append) обязателен, иначе пользователь будет удалён из других групп.

> usermod -s /bin/bash alice

Изменит оболочку.

> usermod -e 2026-12-31 alice

Установит дату истечения учётной записи.

---

## 🔑 Ключевые опции

- `-aG` — добавить в дополнительные группы (append).
- `-l новое_имя` — изменить логин.
- `-d /новый/путь` — изменить домашнюю папку.
- `-L` — заблокировать учётную запись.
- `-U` — разблокировать учётную запись.

> usermod -L compromised_user

Заблокирует учётную запись при расследовании инцидента.

## 🧠 Значимость для меня как специалиста по ИБ

- Я знаю, что при обнаружении скомпрометированной учётной записи первым делом нужно её заблокировать (`usermod -L`), а не удалять, чтобы сохранить улики.
- Я умею добавлять администраторам необходимые группы, не пересоздавая учётную запись.

---

## 💬 Ответ на собеседовании (кратко)

> «`usermod` изменяет параметры пользователя. Я использую его для добавления в группы (`-aG`), смены оболочки, блокировки учётной записи (`-L`). При блокировке пользователь не может войти, но его данные сохраняются для расследования».

## ❓ Самопроверка

1. **Как добавить пользователя в группу `sudo`?**
   👉 `usermod -aG sudo username`
2. **Как заблокировать учётную запись?**
   👉 `usermod -L username`
