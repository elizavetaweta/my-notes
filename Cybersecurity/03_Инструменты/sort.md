# 🔤 sort — сортировка строк

> [!abstract] Суть одной фразой
> `sort` — это команда для сортировки строк в алфавитном или числовом порядке. Для специалиста по ИБ это инструмент упорядочивания логов, списков IP-адресов и результатов аудита перед дальнейшим анализом.

---

## 📌 Базовое использование

**Сортировать файл по алфавиту:**

> sort filename.txt

**Сортировать и вывести только уникальные значения (аналог `sort | uniq`):**

> sort -u filename.txt

---

## 🔑 Ключевые опции

- `-n` (**n**umeric) — числовая сортировка: `2, 10, 100`, а не `10, 100, 2`.
- `-r` (**r**everse) — обратный порядок (по убыванию).
- `-k N` (**k**ey) — сортировать по N-му столбцу (ключу).
- `-t 'символ'` (separator, -t от tab character) — задать разделитель столбцов (по умолчанию пробельная последовательность).
- `-u` (**u**nique) — вывести только уникальные строки (аналог `sort | uniq`, но без дополнительного вызова).
- `-h` (**h**uman-numeric) — правильно сравнивать размеры с буквами (`2G` > `10M`). Без этого флага `sort` сравнивает только первые цифры, и `10M` покажется больше, чем `2G`.

> sort -n -r scores.txt

Отсортирует числа по убыванию.

> sort -t ':' -k 3 -n /etc/passwd

Отсортирует записи пользователей по UID (третье поле).

---

## 🕵️ Сценарии для ИБ

**Найти самые частые IP в логе:**

> cut -d ' ' -f 1 access.log | sort | uniq -c | sort -rn

**Отсортировать список пользователей по UID для поиска аномалий:**

> sort -t ':' -k 3 -n /etc/passwd

## 🧠 Значимость для меня

- Я знаю, что `sort` — обязательный шаг перед `uniq`, потому что `uniq` считает повторы только среди **соседних** строк.
- Я могу быстро упорядочить логи по времени, IP или количеству событий.

## ❓ Самопроверка

1. **Как отсортировать файл по числам?**
   👉 `sort -n файл`
2. **Почему `uniq` работает неправильно без `sort`?**
   👉 `uniq` считает повторы только среди соседних строк, а `sort` группирует одинаковые строки вместе.
