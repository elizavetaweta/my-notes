# 🔎 locate — быстрый поиск файлов по имени через базу данных

> [!abstract] Суть одной фразой
> `locate` — это команда для почти мгновенного поиска файлов и папок по имени. В отличие от [[find]], она не обходит диск, а смотрит в заранее построенную базу данных (`mlocate.db`), что в десятки раз быстрее.

Для специалиста по ИБ `locate` удобен, когда нужно быстро найти, где лежит конфигурационный файл или программа. Однако важно помнить: база обновляется периодически, и свежесозданные или только что удалённые файлы могут не отображаться.

---

## 📌 Базовое использование

> locate имя_файла

Например, найти все файлы, в имени которых есть `sudo`:

> locate sudo

Вывод будет почти мгновенным, даже на больших дисках.

---

## 🔑 Основные опции

- `-i` — игнорировать регистр (находить и `Password`, и `password`).
- `-c` — вывести только количество найденных файлов, а не их список.
- `-l N` — ограничить вывод первыми `N` результатами.
- `-r` — использовать регулярное выражение для поиска.

> locate -i sshd_config

Найдёт файлы `sshd_config`, `Sshd_Config` и другие варианты независимо от регистра.

> locate -c log

Покажет, сколько файлов с «log» в имени существует в системе.

---

## ⚙️ Как обновить базу данных

База `locate` обновляется автоматически раз в сутки (через `updatedb`). Чтобы принудительно обновить её перед поиском свежих файлов:

> sudo updatedb

После этого `locate` будет видеть только что созданные файлы.

> [!note] Для расследования
> Если вы ищете следы недавнего взлома, сначала запустите `updatedb`, чтобы проиндексировать все изменения, сделанные злоумышленником.

## Про саму базу данных:

Эта база данных называется **`locatedb`** (или `mlocate.db` / `plocate.db` в современных системах).

Она представляет собой специальный индексированный файл, который содержит актуальный снимок структуры всей файловой системы компьютера.

📌 Как устроена и работает эта база данных

- **Что внутри**: Простой список абсолютных путей ко всем файлам и папкам на диске.
- **Где хранится**: Обычно находится по пути `/var/lib/mlocate/mlocate.db` или `/var/lib/plocate/plocate.db`.
- **Как обновляется**: База не обновляется сама в реальном времени. Вместо этого в фоне работает утилита **`updatedb`**.
- **Периодичность**: Система автоматически запускает `updatedb` один раз в сутки (через планировщик `cron` или таймеры `systemd`).

## 🆚 `locate` vs [[find]]

| Критерий | `locate` | `find` |
|---|---|---|
| **Скорость** | Почти мгновенно | Медленнее (обходит диск) |
| **Актуальность** | Зависит от времени последнего `updatedb` | Всегда актуально |
| **Поиск по метаданным** | Нет (только имя) | Да (права, владелец, размер, время) |
| **Типовые сценарии** | «Где лежит этот файл?» | «Найди файлы с правами 777» |

Для аудита безопасности используется [[find]], для быстрой навигации — `locate`.

## ❓ Самопроверка

1. **Почему `locate` быстрее `find`?**
   👉 Потому что он не обходит диск, а ищет в заранее построенной базе данных.
2. **Как обновить базу `locate` вручную?**
   👉 `sudo updatedb`
3. **В каком случае `locate` не найдёт существующий файл?**
   👉 Если файл был создан после последнего обновления базы `updatedb`.
