# ⚡ sudo — выполнение команд от имени другого пользователя

> [!abstract] Суть одной фразой
> `sudo` (SuperUser DO) позволяет выполнять отдельные команды от имени `root` или другого пользователя без полного переключения. Все вызовы логируются, что делает его стандартом безопасности в [[Linux]].

---

## 📌 Базовое использование

> sudo apt update

Выполнит обновление пакетов от имени `root`.

> sudo -u alice whoami

Выполнит команду `whoami` от имени `alice` (вернёт `alice`).

**Редактировать файл с привилегиями:**
> sudo nano /etc/hostname

---

## 🔑 Файл `/etc/sudoers`

Права на `sudo` настраиваются в `/etc/sudoers`. Редактировать нужно только через `visudo`, который проверяет синтаксис и предотвращает блокировку доступа.

---

## 🕵️ Значимость для ИБ

- Я знаю, что `sudo` логирует все выполненные команды, поэтому это предпочтительный способ администрирования.
- При аудите проверяю файл `/etc/sudoers` на наличие опасных правил (например, `ALL=(ALL) NOPASSWD: ALL` без ограничений).

---

## 💬 Ответ на собеседовании (кратко)

> «`sudo` позволяет выполнять команды от имени другого пользователя, обычно `root`. Все вызовы логируются. Я использую `sudo` вместо `su` для аудируемости и ограничиваю права в `/etc/sudoers` по принципу наименьших привилегий».

## ❓ Самопроверка

1. **Как выполнить команду от имени пользователя `git`?**
   👉 `sudo -u git команда`
2. **Почему нельзя редактировать `/etc/sudoers` обычным редактором?**
   👉 Ошибка синтаксиса может заблокировать `sudo` для всех. `visudo` проверяет синтаксис перед сохранением.
