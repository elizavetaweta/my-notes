# 🆚 Отличие `awk` от `cut`

> [!abstract] Суть одной фразой
> `cut` — это «нож», который быстро разрезает строки по фиксированному разделителю и достаёт нужный столбец. `awk` — это «комбайн», который умеет не только резать, но и фильтровать, считать, переставлять столбцы и выполнять арифметику в одной команде.

Для специалиста по ИБ выбор между ними определяет скорость и читаемость команды: `cut` — для быстрой нарезки, `awk` — для сложных отчётов и фильтрации.

---

## 📊 Таблица сравнения

| Характеристика | `cut` | `awk` |
|---|---|---|
| **Разделитель** | Один символ (табуляция, двоеточие, пробел) | Любая пробельная последовательность по умолчанию, настраивается через `-F` |
| **Фильтрация** | Нет, только вырезание | Да: условия по содержимому (`$3 > 1000`, `/Failed/`) |
| **Сортировка и подсчёт** | Нет | Да: счётчики, суммы, агрегация |
| **Вывод нескольких полей** | Можно, но порядок жёстко задан | Можно менять порядок: `print $3, $1` |
| **Сложность** | Минимальная, легко запомнить | Выше, но богаче возможности |
| **Скорость** | Быстрее на простых задачах | Быстрее на сложных (один проход вместо конвейера) |

## 🔍 Примеры из ИБ

### Задача: извлечь имена пользователей из `/etc/passwd`

> cut -d ':' -f 1 /etc/passwd

> awk -F ':' '{print $1}' /etc/passwd

Результат одинаковый. `cut` проще, `awk` — универсальнее.

### Задача: найти пользователей с UID ≥ 1000 (обычные пользователи)

> awk -F ':' '$3 >= 1000 {print $1}' /etc/passwd

`cut` эту задачу не решит — нужна ещё команда `grep` и сложный конвейер. `awk` справляется в одиночку.

### Задача: извлечь IP-адрес атакующего из лога

> grep "Failed password" /var/log/auth.log | awk '{print $11}'

Можно и через `cut -d' ' -f11`, но если количество пробелов между полями разное, `awk` надёжнее: он «схлопывает» повторяющиеся пробелы.

## 💡 Правило выбора

- **Нужно просто вытащить один столбец из структурированного файла с известным разделителем** → `cut`.
- **Нужно отфильтровать по значению, посчитать, переставить столбцы или вывести несколько полей в новом порядке** → `awk`.

## 🔗 Связи

- [[cut]] — простое вырезание столбцов.
- [[awk]] — мощная обработка текста.
- [[grep]] — фильтрация строк, часто комбинируется с `cut` и `awk`.
- [[sort]], [[uniq]] — постобработка результатов.

## 🧠 Значимость для меня как специалиста по ИБ

- Я знаю, что `cut` экономит время при просмотре конфигурационных файлов и логов с фиксированной структурой.
- Я понимаю, что `awk` незаменим для быстрого аудита: найти всех пользователей с UID 0, кроме root, или посчитать количество попыток входа с каждого IP.
- Я выбираю инструмент под задачу, а не использую один на все случаи.

## 💬 Ответ на собеседовании (кратко)

> «`cut` быстро вырезает колонки по разделителю, `awk` — это целый язык обработки текста: фильтрация, арифметика, форматирование. Для простых задач я использую `cut`, для анализа логов и аудита — `awk`, потому что он может заменить целый конвейер из `grep`, `cut` и `sort`».

## ❓ Самопроверка

1. **Как `awk` обрабатывает несколько пробелов подряд?**
   👉 По умолчанию считает их одним разделителем, в отличие от `cut`, который каждый пробел считает отдельным полем.
2. **Можно ли `awk` использовать как простой `cut`?**
   👉 Да, `awk '{print $1}'` работает аналогично `cut -d' ' -f1`, но `awk` ещё и схлопывает множественные пробелы.
3. **В каком случае `cut` предпочтительнее?**
   👉 Когда файл имеет строгий формат с одним символом-разделителем (CSV, `/etc/passwd`) и нужна только нарезка колонок.
