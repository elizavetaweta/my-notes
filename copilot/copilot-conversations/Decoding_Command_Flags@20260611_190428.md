### 🔑 Полезные опции `ls`

- **`-l` (long)** – подробный вывод: права доступа (`rwx`), владелец, группа, размер, дата изменения.  
  👉 Основа любого аудита. Без этого флага вы не увидите ни прав, ни владельцев – невозможно понять, не выставлены ли избыточные разрешения ([^1]).  

- **`-a` (all)** – показать все файлы, включая скрытые (начинаются с точки, например `.bashrc`, `.ssh`).  
  👉 Злоумышленники часто прячут файлы с точкой в начале имени. Без `-a` вы пропустите бэкдоры или скопированные ключи ([^1]).  

- **`-h` (human‑readable)** – размеры в удобном виде: `1.2K`, `4.0M`, `1G` вместо столбцов байт.  
  👉 Ускоряет чтение логов и поиск подозрительно больших (или маленьких) файлов во время разбора инцидента.  

- **`-t` (time)** – сортировка по времени последнего изменения (сначала свежие).  
  👉 Позволяет мгновенно увидеть, какие файлы недавно модифицировались – именно там могут быть следы атаки.  

- **`-r` (reverse)** – обратный порядок сортировки.  
  👉 В комбинации с `-t` (`ls -ltr`) выводит старые файлы первыми – удобно искать дропнутые скрипты, которые были созданы раньше всего.  

- **`-R` (recursive)** – рекурсивный обход: показывает содержимое всех вложенных папок.  
  👉 Используется для тотального аудита структуры каталогов (`ls -laR /tmp`), чтобы не пропустить вредоносный файл в глубокой подпапке ([^1]).

### 🛡️ Типичная связка для расследования
```bash
ls -lah /tmp
```
– показывает **все** (включая скрытые) файлы в `/tmp` с читаемыми размерами и полными правами. Это первая команда при проверке временной папки на подозрительную активность ([^1]).
